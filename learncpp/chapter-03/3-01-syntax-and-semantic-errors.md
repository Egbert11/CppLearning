# 3.1 Syntax and semantic errors

> 原文：https://www.learncpp.com/cpp-tutorial/syntax-and-semantic-errors/

## 核心概念

- 本章的主题是"发现并消除程序中的 bug"，其中也包括使用 IDE 内置的调试器（integrated debugger）。
- 调试（debugging）所用的工具和方法并不属于 C++ 标准的一部分；即便如此，学会它们仍被形容为"成为成功程序员极其重要的一环"。
- 错误总体上分为两大类：**语法错误（syntax error）**与**语义错误（semantic error，也叫逻辑错误 logic error）**。
- **语法错误**：当一条语句不符合 C++ 的语法（grammar）时发生，例如漏写分号、圆括号/花括号不匹配。
- 编译器会捕获语法错误，以警告或错误的形式报告出来，因此它们容易定位——反复编译、逐一修正直到编译干净即可。
- **语义错误**：语句在语法上是合法的，但违反了语言的其他规则，或没有做到作者想让它做的事，即"含义上的错误"。
- 一部分语义错误发生在**编译期**：例如使用了未声明的变量、类型不匹配（拿错类型的对象去用）。
- 另一部分语义错误只在**运行期**出现：可能让程序崩溃（如除以 0），但更常见的是产生一个错误的值或行为。
- 运行期的语义错误**很难发现**：在非平凡的程序里，靠肉眼读代码往往看不出问题——这正是需要学习调试技巧的原因。
