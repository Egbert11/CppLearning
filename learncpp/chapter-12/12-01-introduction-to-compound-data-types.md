# 12.1 Introduction to compound data types

> 原文：https://www.learncpp.com/cpp-tutorial/introduction-to-compound-data-types/

## 核心概念

- **回顾基本类型**：4.1 介绍了 C++ 核心语言提供的基本数据类型，它们对付简单需求足够，但覆盖不了所有情况。
- **动机一：分数**。用两个独立的 `int`（分子、分母）表示一个分数，虽然能工作，但"这两个变量是一对"只存在于注释和上下文里，代码没有任何机制把它们关联起来。
- **动机一续：DRY 与单一返回值**。按"不要重复自己"原则，输入处理应放进函数，但函数只能返回一个值，把分子和分母一起交回调用者很别扭。
- **动机二：扩展性**。把员工 ID 存成 `id1`、`id2`、`id3`…… 无法扩展：100 名员工就要 100 个变量名，打印和传参都会变得痛苦。
- **复合数据类型（compound data type）**：又称"组合数据类型（composite data type）"，指**由其他已有数据类型定义出来的类型**，并自带适合特定问题的额外属性与行为。
- **关键规则**：每个数据类型要么是基本类型，要么是复合类型；**C++ 标准明确规定每个类型属于哪一类**。复合类型可以解决上述所有难题。
- **C++ 复合类型清单**：函数；C 风格数组；指针类型（指向对象的指针、指向函数的指针）；指向成员的类型（指向数据成员的指针、指向成员函数的指针）；引用类型（左值引用、右值引用）；枚举类型（无作用域枚举、有作用域枚举）；类类型（struct、class、union）。
- **函数本身就是复合类型**：一个接收 `(int, double)` 返回 `void` 的函数，其类型是 `void(int, double)`；该类型由基本类型构造而来，所以函数类型是复合类型，并且有"可被调用"等行为。
- **本章覆盖计划**：本章讲较直接的复合类型，主要是左值引用和指针；下一章讲无作用域/有作用域枚举，以及第一个类类型 `struct`；更后面的章节引入类和数组类型，其中包括 `std::string`——"它其实是一个类类型！"
- **术语（Nomenclature）**：**类类型（class type）**指一个类型是 struct、class 或 union；该术语在后续课程中频繁使用。

## 最佳实践

本节无 Best practice / Rule / Warning 条目。仅有 **Key insight**：

- "每个数据类型要么是基本类型，要么是复合类型。C++ 标准明确规定每个类型属于哪一类。"
