## 本章知识速览

- **复合（composite）数据类型**：由基本类型或其它复合类型构造出来的类型。
- **值类别（value category）**：告诉你一个表达式解析为值、函数还是对象。
- **左值（lvalue）**：求值为一个具有标识（identity）的函数或对象的表达式。
- **标识（identity）**：具有标识符，或具有可确定的内存地址。
- **可修改/不可修改左值**：前者可被改动；后者不行（通常是因为 `const`/`constexpr`）。
- **右值（rvalue）**：任何不是左值的表达式；包括字面量（字符串字面量除外）以及按值返回的函数/运算符返回值。
- **引用**：**一个已有对象的别名**；对它的一切操作都作用于被引用对象。C++ 有左值引用与右值引用。
- **左值引用**：通常直接称“引用”；给一个已有左值起别名。**左值引用变量**即充当这种引用的变量。
- **绑定/被引用对象（referent）**：用一个对象初始化引用即“绑定”到它；该对象就是 referent。
- **非 const 引用的限制**：左值引用不能绑定到不可修改左值或右值，否则就能改动 const 数据。因此它又叫“指向非 const 的左值引用”。
- **不能重设（reseat）**：引用一旦初始化，就不能再让它去给别的对象起别名。
- **悬垂引用**：其 referent 先被销毁的引用；使用它是未定义行为。
- **指向 const 的左值引用**（又称“指向 const 的引用”“const 引用”）：加 `const` 使 referent 被当作 const。它可以绑定可修改左值、不可修改左值与右值。
- **临时对象**（无名/匿名对象）：为临时使用而创建、在单条表达式内销毁。
- **按引用传递**：形参声明为引用，调用时绑定到实参，因此不复制实参。
- **取地址运算符（`&`）**：返回其操作数的内存地址。
- **解引用运算符（`*`）**：返回某地址处的值，该值是左值。
- **指针**：一个把内存地址（通常是别的变量的地址）作为其值的对象。指针默认不被初始化。
- **野指针（wild pointer）**：从未初始化过的指针。
- **悬垂指针（dangling pointer）**：持有已失效对象地址的指针。
- **空值/null 指针/`nullptr`**：指针还可以持有特殊的“无值”状态，指向空。`nullptr` 是空指针字面量，可用于显式初始化或赋值。
- **指针安全规则**：指针要么持有有效对象的地址，要么是 `nullptr`；这样只需做一次空检查，任何非空指针都可信。
- **指向 const 值的指针**：一个（非 const 的）指针，指向常量值。
- **const 指针**：初始化后地址不可改变的指针。
- **指向 const 值的 const 指针**：既不能改地址，也不能改所指的值。
- **按地址传递**：调用方通过指针提供对象地址；该指针被复制进形参，函数解引用它以访问原对象。
- **按引用返回**：返回绑定到被返回对象的引用，避免复制；对象必须活得比函数久，否则引用悬垂。按引用返回引用形参是安全的。
- **按引用返回的复制规则**：若这样的返回值用于初始化或赋值一个非引用变量，会像按值返回那样被复制。
- **`auto` 类型推导**：从推导类型中丢弃引用和顶层 const 限定符；可在声明中重新施加。
- **按地址返回**：与按引用返回类似，但返回的是指向对象的指针。

## 测验

1. **判断左值/右值**：对以下由 `<<` 打印的表达式，指出每个是左值还是右值：
   - (a) `std::cout << 5;`
   - (b) `int x { 5 }; std::cout << x;`
   - (c) `int x { 5 }; std::cout << x + 1;`
   - (d) `int foo() { return 5; } std::cout << foo();`
   - (e) `int& max(int &x, int &y) { return x > y ? x : y; } int x { 5 }; int y { 6 }; std::cout << max(x, y);`

   解答代码：[12-16-quiz1.cpp](12-16-quiz1.cpp)（答案：(a) 右值 (b) 左值 (c) 右值 (d) 右值 (e) 左值）。

2. **程序输出**：下面程序输出什么？
   ```cpp
   int x{ 4 };
   int y{ 6 };
   int& ref{ x };
   ++ref;
   ref = y;
   ++ref;
   std::cout << x << ' ' << y;
   ```
   解答与代码：[12-16-quiz2.cpp](12-16-quiz2.cpp)（答案：`7 6`；因为引用不能重设，`ref = y` 等价于 `x = y`）。

3. **为什么优先按 const 引用而非非 const 引用传递**（尽可能时）？给出两个理由。
   - 非 const 引用形参允许修改实参；若并不需要修改，const 引用能防止意外改动。
   - 非 const 引用形参只接受可修改左值；而 const 引用形参还能接受不可修改左值和右值。

4. **const 指针 vs. 指向 const 的指针有何区别？**

   - 指向 const 的指针：可以重新指向，但不能通过它修改所指的值。
