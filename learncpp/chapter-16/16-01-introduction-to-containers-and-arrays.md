# 16.1 Introduction to containers and arrays

> 原文：https://www.learncpp.com/cpp-tutorial/introduction-to-containers-and-arrays/

## 核心概念

- **变量扩展性难题**：要记录 30 个测验成绩就需要 30 个各自命名的变量，求平均值的表达式会变得又长又重复，还容易打错字。
- **后续增删数据很脆弱**：插入第 31 名学生就得手动到处改代码，而且很容易忘记把除数从 30 改成 31，造成语义错误。
- **结构体也不能解决**：把成绩装进 struct 只带来一点组织性，仍然必须逐个定义和访问每个成员。
- **容器的通用定义**：容器（container）是一种数据类型，为"一组没有名字的对象"提供存储，这些对象称为元素（element）。
- **Key insight（何时使用容器）**：当我们"需要处理一组相关的值时"，通常就会用到容器。
- **字符串本身就是容器**：`std::string` 存储一组字符，可以当作文本一次性输出。
- **元素没有名字**：容器自身有名字，但它内部的元素没有名字，因此容器想装多少元素都行，不必为每个元素起名。
- **结构体为什么不算容器**：普通 struct 的每个数据成员都必须有唯一名字，这正是它与真正容器的区别。
- **访问元素**：每种容器都提供一种或多种访问元素的方法，具体机制取决于容器类型。
- **容器长度**：元素个数称为容器的"长度"（length，有时也叫 count）；`std::string::length()` 返回字符个数。
- **length 与 size 的术语区分**：C++ 中 "size" 也常用来表示元素个数，但它容易与 `sizeof` 返回的内存占用混淆；本教程约定用 "length" 表示元素个数，用 "size" 表示存储占用。
- **容器的典型操作**：创建（空、预置长度、或从列表构造）、访问元素、插入/删除元素、获取元素个数。
- **容器能力与性能各不相同**：不同容器类型支持的操作及速度不同，选对容器会影响可维护性与性能。
- **元素类型同质**：在多数语言（含 C++）中，容器内所有元素必须同一类型；元素类型常由用户指定。
- **用类模板实现灵活性**：C++ 容器通常是类模板，你只需把元素类型作为模板实参传入，而无需为每种元素类型新建一个容器类型。
- **异质容器（旁注）**：相反的一类容器允许混合元素类型，通常出现在 Python 等脚本语言中。
- **C++ 中的容器**：Containers 库是 C++ 标准库的一部分；实现容器的类类型称为"容器类（container class）"。
- **更窄的 C++ 定义**：严格来说只有 Containers 库中的类类型才算容器；本教程一般用"容器"，对标准库中的则用"容器类"。
- **For advanced readers（标准意义上的非容器）**：C 风格数组、`std::string` 与 `std::vector<bool>` 不满足 C++ 标准的容器要求；后两者被称为"伪容器（pseudo-container）"，因为它们满足大部分要求。
- **要求意味着必须是类类型**：C++ 容器必须实现所列要求（包括若干成员函数），因此必须是类类型。
- **最常用的容器**：`std::vector` 与 `std::array` 占主导；其他容器类适用于特定场景。
- **数组的定义**：数组是一种容器数据类型，把一串值连续（contiguously）存储、中间没有空隙，因此能快速直接访问任意元素。
- **三种主要数组类型**：
  - C 风格数组（继承自 C，定义在核心语言中，又叫 "C arrays"、"naked arrays"、"fixed arrays" 等，按现代标准被认为是危险的）；
  - `std::vector`（C++03 引入，最灵活）；
  - `std::array`（C++11 引入，功能更受限但有时更高效，用于替代 C 风格数组）。
- **后续方向**：下一节介绍 `std::vector`；由于各容器接口相似，学会一个后其他都更容易上手。

## 最佳实践

- **Key insight（何时使用容器）**：需要处理一组相关的值时，通常使用容器。
- **Key insight（元素无名字）**：元素本身没有名字，因此容器能装任意多个元素而无需逐一命名。
- **Key insight（访问元素）**：每种容器都提供访问元素的方式，但具体方法取决于容器类型。
- **For advanced readers**：C 风格数组、`std::string`、`std::vector<bool>` 符合容器的通用定义，但不满足 C++ 标准对容器的要求；后两者称为伪容器。
- **Author's note（术语）**：当某说法适用于大多数标准库容器时，教程使用 "container classes"；当某说法适用于所有数组类型时，使用 "array"。

本节无 Best practice / Warning 条目。
