# 17.12 Multidimensional C-style Arrays

> 原文：https://www.learncpp.com/cpp-tutorial/multidimensional-c-style-arrays/

## 核心概念

- **动机场景**：井字棋棋盘是一个 3×3 网格；与其定义九个变量，不如用数组来存放这类重复元素。
- **一维数组**：`int ttt[9];` 这样的 C 风格数组把元素顺序存放在单行内存中。
- **维度（dimension）的定义**：挑选出一个元素所需的**下标个数**。一个下标的数组称为**单维/一维数组**（1d array）。
- **数组的数组**：数组元素可以是任意对象类型，因此元素类型本身也可以是数组；"数组的数组"就是**二维数组**（2d array），需要两个下标。
- **行/列约定**：对 2d 数组，习惯把左边的下标读作行选择器，右边的读作列选择器。
- **访问元素**：两个下标一起使用，写作 `a[row][col]`；于是井字棋棋盘写成 `int ttt[3][3];`。
- **多维数组**：维度超过一个的数组。C++ 允许两个以上维度，例如 4×4×4；Minecraft 的 16×16×16 区块段就是现实案例。三维以上允许但不常见。
- **线性内存 / 行主序**：内存本身是一维的，所以多维数组其实以扁平序列存储。C++ 按**行**依次存放元素，从左到右、从上到下（row-major）。
- **列主序**：别的语言（尤以 Fortran 为代表）按列存放，从上到下、从左到右。
- **初始化与遍历顺序**：元素按行主序初始化；以同样顺序遍历多维数组是最高效的访问方式。
- **嵌套花括号初始化**：把每一行的值各自包在一对花括号里，是初始化 2d 数组最清晰的方式。作者明确建议：即便某些编译器允许省略内层花括号，也应当保留，以提高可读性。
- **部分初始化**：使用内层花括号时，某行未指定的元素会被值初始化（`int` 即 0）。
- **省略最左边长度**：提供初始化列表时，只有最左边那一维可以省略；编译器会数初始化器来推导。省略任何非最左边的维度都是非法的。
- **零初始化**：与普通数组一样，可用空花括号把多维数组全部初始化为 0，如 `int array[3][5] {};`。
- **二维迭代**：每个维度一层循环；行循环放外层、列循环放内层，与行主序布局一致，效率最高。
- **范围 for 替代**：嵌套的范围 for 可以先遍历行、再遍历行内元素，行通常用 `const auto&` 绑定。
- **实战案例**：乘法表程序填充一个 10×10 数组并打印第 1 到第 9 行/列，故意跳过索引 0（因为乘以 0 只会得到 0）。输出是 9×9 网格，每格为行号与列号之积。
- **笛卡尔坐标 vs 数组坐标**：笛卡尔用 { x, y } 对，x 水平、y 垂直（y 轴有时翻转）。数组索引也是 2d 坐标系 `[row][col]`，其列轴相对直觉是翻转的。
- **转换规则**：转换方式反直觉——笛卡尔的 **x** 对应数组的**列**，笛卡尔的 **y** 对应数组的**行**，所以 `{ x, y }` 变成 `[y][x]`。遵循此约定的循环用 y 作外层、x 作内层，索引写作 `a[y][x]`。

## 最佳实践

- 本节原文没有加框的 Best practice / Author's note / Warning。最接近的是两条行内建议：
  - 嵌套初始化列表中的内层花括号应当保留（即便编译器允许省略），因为它有助于可读性。
  - 遍历多维数组时应按元素在内存中的排列顺序（行主序）进行，以获得最佳效率。
