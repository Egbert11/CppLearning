# 10.1 Implicit type conversion

> 原文：https://www.learncpp.com/cpp-tutorial/implicit-type-conversion/

## 核心概念

- **类型转换（type conversion）**：把数据从一种类型变成另一种类型的动作。多数时候源数据本身不变，转换产出一个新值。
- **隐式类型转换（implicit type conversion，又称自动类型转换 / 强制转换 coercion）**：当需要一种类型却提供了另一种类型时，编译器自动完成转换。C++ 中绝大多数转换属于此类。
- **显式类型转换（explicit type conversion）**：程序员用转换运算符（cast operator，如 `static_cast`）主动要求的转换。
- **转换不改变源数据**：原始值作为输入，转换过程输出一个转换后的结果。
- **临时对象规则**：把一个值转换后，会产生一个目标类型的**临时对象（temporary object）**来存放转换结果。
- **为什么需要转换**：值本质是一串二进制位，其**类型**告诉编译器如何解读这些位。同一个数值在不同类型里的位模式可能完全不同（整数 `3` 与浮点 `3.0`），所以位不能直接照抄。
- **隐式转换发生的场合**：
  - 用不同类型的值初始化或给变量赋值；
  - 函数返回值类型与声明的返回类型不一致；
  - 二元运算符的两个操作数类型不同；
  - 在 `if` 语句中使用非布尔值；
  - 函数实参类型与形参类型不一致。
- **标准转换（standard conversions）**：语言为核心类型（以及数组、引用、指针、枚举等某些复合类型）定义的转换规则。截至 C++23 共有 14 种，分成 5 类：
  - **数值提升（numeric promotions）**：较小整型提升为 `int`/`unsigned int`，`float` 提升为 `double`。
  - **数值转换（numeric conversions）**：除提升之外的整型与浮点型转换（如 `int` → `float`）。
  - **限定转换（qualification conversions）**：增删 `const`/`volatile`。
  - **值变换（value transformations）**：改变表达式的值类别。
  - **指针转换（pointer conversions）**：`std::nullptr` 到指针，或指针之间。
- **转换可能失败**：若编译器找不到可接受的转换，编译报错（例如字符串字面量到 `int` 没有标准转换）。
- **花括号初始化禁止窄化**：即使某种转换已知可行，用花括号初始化时若会丢失数据仍会被拒绝（见 10.4）。
- **可能存在歧义**：有时编译器无法在多个候选转换中选最优者（在重载解析中讨论）。
- **整体复杂度**：完整的转换规则很长很细，但大多数情况下"自然就好用"。
