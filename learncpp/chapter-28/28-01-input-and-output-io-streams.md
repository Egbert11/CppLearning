# 28.1 Input and output (I/O) streams

> 原文：https://www.learncpp.com/cpp-tutorial/input-and-output-io-streams/

## 核心概念

- **I/O 不属于核心语言，而由标准库提供**：输入输出不是 C++ 语言本身的一部分，而是通过标准库实现，因此位于 `std` 命名空间中。之前你已经用过 `iostream` 头里的 `cin` / `cout`，本节更深入地看 `iostream` 库。
- **iostream 类层次**：包含 `iostream` 头后，你就获得了一整套负责 I/O 的类（其中有一个类本身就叫 `iostream`）。非文件 I/O 的类层次图可参见 cppreference。
- **多重继承**：这个层次使用了多重继承（一个通常建议尽量避免的特性）；但 iostream 库经过精心设计和大量测试，规避了多重继承的常见问题，可以放心使用。
- **stream（流）的定义**：抽象地说，**流**就是一个"可按顺序访问的字节序列"。随着时间推移，流可能产生或消耗任意数量的数据。
- **输入流（input stream）**：用于保存来自数据生产者（键盘、文件、网络等）的输入。例如用户在程序尚未期待输入时按键，该按键不会丢失，而是放入输入流中，等待程序准备好时再处理。
- **输出流（output stream）**：用于保存将要交给消费者（显示器、文件、打印机等）的输出。如果设备尚未就绪（比如打印机还在预热），数据会在流中等待，直到被消费。
- **有些设备既输入又输出**：文件和网络既可作输入源，也可作输出目标。
- **为什么要用流**：程序员只需学会操作"流"，就能读写多种设备；流如何与底层设备交互，是运行环境/操作系统的职责。
- **`ios`**：`std::basic_ios<char>` 的 typedef，定义了输入流与输出流共用的内容（后续小节详述）。
- **`istream` 与提取运算符 `>>`**：`istream` 是主要的输入流类，提取运算符 `>>` 从流中取出值——呼应"按键进入流、程序把值取出来"的模型。
- **`ostream` 与插入运算符 `<<`**：`ostream` 是主要的输出流类，插入运算符 `<<` 把值放进流中，交由消费者（如显示器）使用。
- **`iostream`**：同时支持输入与输出两个方向，可实现双向 I/O。
- **标准流（standard stream）的定义**：**标准流**是"由运行环境提供给计算机程序的、已预先连接好的流"。C++ 提供四个现成的标准流对象。
- **四个标准流**：
  - `cin` —— 绑定到标准输入的 `istream`，通常是键盘
  - `cout` —— 绑定到标准输出的 `ostream`，通常是显示器
  - `cerr` —— 绑定到标准错误的 `ostream`，通常是显示器，**无缓冲**
  - `clog` —— 绑定到标准错误的 `ostream`，通常是显示器，**有缓冲**
- **缓冲 vs 无缓冲**：无缓冲输出一般会立即处理；有缓冲输出通常会攒成一块再写出。由于 `clog` 很少使用，常被从标准流列表中省略。
