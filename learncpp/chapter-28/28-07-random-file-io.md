# 28.7 Random file I/O

> 原文：https://www.learncpp.com/cpp-tutorial/random-file-io/

## 核心概念

- **文件指针（file pointer）**：每个文件流类都维护一个文件指针，标记当前读写位置；I/O 就发生在该位置。默认指针在文件开头，但"若文件以追加模式打开，文件指针会移到文件末尾"。
- **顺序访问 vs 随机访问**：前面几节都是按顺序读写（顺序访问）。随机文件访问让你"跳到文件中各个位置"，当文件保存着记录、而你想要其中某条记录、又不想先读它前面的所有内容时很有用。
- **`seekg()` 与 `seekp()`**：随机访问通过操作文件指针完成：`seekg()` 用于输入、`seekp()` 用于输出，"g 代表 get，p 代表 put"。对**文件流**而言读位置与写位置总是相同的，因此两者可互换使用。
- **两个参数**：第一个是字节偏移量；第二个是 ios 标志，说明偏移是从哪里量起的。正偏移向文件末尾移动，负偏移向文件开头移动。
- **三个定位标志**：`beg` = 相对于文件开头（默认）；`cur` = 相对于当前文件指针位置；`end` = 相对于文件末尾。
- **文本文件警告**：在文本文件中，定位到文件开头以外的位置"可能导致意外行为"，因为换行是一种抽象：Windows 用 CR+LF（2 字节），Unix 用 LF（1 字节）。跨换行定位因此消耗的字节数随编码而变。某些操作系统还会用尾部零字节填充文件，改变相对于末尾的定位结果。
- **优先用二进制文件**：原文指出 `seekg()` / `seekp()` 更适合用在二进制文件上；可用 `std::ifstream::binary` 请求二进制模式。
- **`tellg()` 与 `tellp()`**：返回文件指针的绝对位置，可用于求文件大小。
- **用 `fstream` 混合读写**：`fstream` 能读写同一个文件，但有注意事项：不能随意在读写之间切换。一次读或写之后，唯一能切换的办法是执行一个改变文件位置的操作（seek）。如果指针已经在你想要的位置，就 seek 到当前位置——否则"可能发生各种奇怪的事情"。原文还指出 `iofile.seekg(0, std::ios::cur)` 可能被某些编译器优化掉。此外与 `ifstream` 不同，用 `fstream` 时 `while (inf)` 不能用来测试是否还有数据。
- **其它工具**：用 `remove()` 删除文件；`is_open()` 在流已打开时返回 true，否则返回 false。
- **指针与磁盘 I/O**：把指针值（内存地址）写入磁盘是危险的，因为变量的地址在每次执行时可能不同，读回时存下的地址便已失效。

## 最佳实践

本节无 Best practice 方框，但有两条 Warning 与一条 Author's note：

- **Warning（文本文件）**："在文本文件中，定位到文件开头以外的位置可能导致意外行为。" 原因是换行编码差异（CR+LF vs LF），以及"某些操作系统中文件可能被尾部零字节填充"。
- **Warning（把指针写入磁盘）**："不要把内存地址写入文件。原本位于那些地址的变量，在从磁盘读回值时可能已处于不同地址，那些地址将会失效。"
- **Author's note**：文件大小 `64` 的结果出现在 Windows 上；"如果你在 Unix 上运行该示例，会得到 `60`"，因为换行表示更小。若文件带尾部零字节填充，结果也可能不同。

原文中还有若干**片段**无法作为独立可运行程序，仅在此列出（取自原文逐字块）：

- `seekg()` 偏移量片段：`inf.seekg(14, std::ios::cur);`（向前 14 字节）、`inf.seekg(-18, std::ios::cur);`（向后 18 字节）、`inf.seekg(22, std::ios::beg);`（移到第 22 字节）、`inf.seekg(24);`（移到第 24 字节，默认 beg）、`inf.seekg(-28, std::ios::end);`（移到距末尾 28 字节处）。
- 移到开头/末尾：`inf.seekg(0, std::ios::beg);`、`inf.seekg(0, std::ios::end);`。
- 二进制模式：`std::ifstream inf {"Sample.txt", std::ifstream::binary};`。
- 定位到当前位置（`fstream` 切换读写模式）：`iofile.seekg(iofile.tellg(), std::ios::beg);`。
