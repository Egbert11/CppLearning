## 核心概念

- 运算符重载把“函数重载”扩展到类：让自定义类型也能用运算符。运算符的含义应尽量贴近其原本语义；含义不直观时优先用具名函数。
- 运算符可重载为普通函数、友元函数或成员函数。经验法则：
  - `=`、`[]`、`()`、`->` → 成员函数。
  - 一元运算符 → 成员函数。
  - 修改左操作数的二元运算符（如 `+=`）→ 尽量做成员函数。
  - 不修改左操作数的二元运算符（如 `+`）→ 普通/友元函数。
- 类型转换可重载为转换函数，用于显式或隐式地转成另一类型。
- 拷贝构造函数由同类型对象初始化一个对象；用于“用同类型对象做直接/统一初始化、拷贝初始化、按值传参 / 返回”。
- 不写拷贝构造函数时编译器会生成一个“逐成员初始化”的版本；即便它有副作用也可能被省略（拷贝消除），不要依赖它一定被调用。
- 构造函数默认是转换构造函数（允许隐式转换）；用 `explicit` 可禁止。函数可被 `delete`（含拷贝构造 / 赋值），被调用会产生编译错误。
- 赋值运算符可以重载；不写则编译器提供一个。**始终加自赋值检查**（除非类天然安全或用 copy-and-swap）。
- 区分两者：需要“先创建新对象”时（含按值传参 / 返回）用拷贝构造；无需新对象时用赋值运算符。
- 编译器的默认实现做逐成员初始化 / 赋值——即**浅拷贝**。涉及动态分配时通常出问题（共享内存），应自定义为**深拷贝**；更好的做法是优先用标准库类，别自己管内存。

## 最佳实践

- 含义不直观的运算符应改成具名函数；运算符的行为要贴近直觉。
- 二元运算符中“修改左操作数”的用成员函数，“不修改左操作数”的用普通/友元函数。
- 类型转换与单参数转换构造函数一样，通常应标 `explicit`；优先转换构造函数而非重载类型转换。
- 赋值运算符始终写自赋值检查（`if (this == &other) return *this;`）。
- 有动态成员时，拷贝构造与赋值都要做深拷贝；优先使用 `std::string`、`std::vector` 等标准库类型。

## 本章知识速览

| 主题 | 关键点 |
|---|---|
| 重载方式选择 | `= [] () ->` 与一元运算符用成员；修改左操作数的二元运算符尽量成员；其余用普通/友元 |
| 下标 `operator[]` | 必须是成员、一个参数；返回引用以支持赋值；另提供 const 重载；可做越界检查 |
| 括号 `operator()` | 必须成员；参数个数/类型任意；用于多维索引或仿函数；勿滥用 |
| 类型转换 `operator T()` | 非静态成员、`const`、无参数、无返回类型；一般标 `explicit`；优先转换构造函数 |
| 拷贝赋值 `operator=` | 成员函数；返回 `*this` 支持链式；**自赋值检查**；动态成员需先释放再深拷 |
| 拷贝构造 vs 赋值 | 需创建新对象（含按值传参/返回）→ 拷贝构造；否则 → 赋值 |
| 浅拷贝 vs 深拷贝 | 默认逐成员=浅拷贝；有动态成员必须深拷贝；优先标准库容器 / `std::string` |
| 运算符与函数模板 | 模板实例化只用到实参类型支持的运算符；缺哪个就补哪个（如 `operator<`） |

## 测验

1. **测验 1**（概念）：对类 `Point` 与实例 `point`，下列每个运算符应实现为“普通/友元函数”还是“成员函数”？
   - a) `point + point`
   - b) `-point`
   - c) `std::cout << point`
   - d) `point = 5;`
   - 解答见 [21-15-quiz1.cpp](21-15-quiz1.cpp)。

2. **测验 2**：写一个 `Average` 类跟踪传入整数的平均值，用两个成员：`std::int32_t` 存累加和、一个计数器存个数。
   - a) 实现后使给定 `main`（默认构造，`avg += 4; avg += 8; avg += 24; avg += -10; (avg += 6) += 10;` 以及 `Average copy{ avg };`）输出 `0 4 6 12 6.5 7 7`。
   - b) 是否应提供自定义拷贝构造 / 赋值运算符？（答：不需要，成员逐个复制即可。）
   - c) 为何用 `std::int32_t` 而非 `int`？（答：`int` 在某些平台可能只有 16 位，最大仅 32767。）
   - 解答见 [21-15-quiz2.cpp](21-15-quiz2.cpp)。

3. **测验 3**：从零写一个 `IntArray` 类（不得用 `std::array` / `std::vector`），构造时确定长度并动态分配，用 assert 做边界检查。使其支持：`fillArray()` 赋 `5 8 2 3 6`、用返回的临时对象构造、自引用赋值、`IntArray b(1); b = a;`、`a[4] = 7;`——输出应两次为 `5 8 2 3 6`。
   - 解答见 [21-15-quiz3.cpp](21-15-quiz3.cpp)。

4. **测验 4（额外加分）**：实现 `FixedPoint2`——两位小数的定点数（范围 −32768.99 ~ 32767.99），无精度误差、省空间。
   - Step 1：选择成员变量类型。
   - Step 2：实现 `FixedPoint2`（base 或 decimal 任一为负则整体为负），支持 `operator<<` 与转 `double`。
   - Step 3：处理越界的小数部分（作相关处理：`m_base += m_decimal / 100; m_decimal = m_decimal % 100;`），并用 `testDecimal` 测试。
   - Step 4：增加接收 `double` 的构造函数，正确四舍五入（处理 `5.0099999…` 与 ±100 的情形）。
   - Step 5：重载 `operator==`、`operator>>`、一元 `operator-`、二元 `operator+`。
   - 解答见 [21-15-quiz4.cpp](21-15-quiz4.cpp)。
