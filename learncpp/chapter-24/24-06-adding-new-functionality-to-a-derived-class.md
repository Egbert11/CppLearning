# 24.6 Adding new functionality to a derived class

> 原文：https://www.learncpp.com/cpp-tutorial/adding-new-functionality-to-a-derived-class/

## 核心概念

- **复用是派生类的一大优势**：有了派生类，就能继承基类的行为，然后"**添加新功能、修改现有功能，或隐藏你不想要的功能**"。
- **若你拥有基类源码，可以直接改它**：当你手上有基类的代码时，就地扩展它是一种选择。
- **修改第三方基类往往是坏主意**：如果厂商发布了更新，你的改动可能丢失，或需要费力且易错的手工合并。
- **有时根本改不了**：标准库代码无法编辑，但你仍可以从它派生，把新增功能放进派生类；以"头文件 + 预编译代码"形式交付的库同理。
- **这些情况下首选的做法是派生**：自己写一个派生类，把额外行为放进去。
- **protected 基类成员可被派生类直接使用**：因为 `m_value` 在 `Base` 中声明为 protected，派生类无需基类提供任何访问器就能直接用它。
- **添加行为就是普通声明**：你像声明任何别的函数一样，在派生类里声明这个新成员函数即可。
- **访问是单向的**：派生对象是一个基对象，所以它可以用基类成员；反过来永远不成立——基对象不能用任何声明在派生类里的东西。

## 最佳实践

本节无独立的 Best practice / Warning / Author's note 框。最接近指导性表述的是：对你无法掌控的基类，应选择派生而不是直接修改。
