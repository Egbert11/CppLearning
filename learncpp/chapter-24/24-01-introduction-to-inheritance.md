# 24.1 Introduction to inheritance

> 原文：https://www.learncpp.com/cpp-tutorial/introduction-to-inheritance/

## 核心概念

- **对象组合回顾**：可以用更简单的类与类型拼装出复杂类，它适合对象与其部分之间构成 "has-a（有一个）" 关系的场景。
- **继承是第二种方式**：继承是 C++ 构造复杂类的另一种主要手段，它建模的是两个对象之间的 "**is-a（是一个）**" 关系。
- **继承与组合的区别**：组合是把其他对象"合起来并连接"；继承则是通过"**直接获得其他对象的属性与行为**"，再对其扩展或特化，从而创造新对象。
- **日常类比**：人从父母那里继承特征，又发展出自己独特的个性；科技产品会承袭前代的功能（常常是为了向后兼容）；C++ 也从 C 语言继承了许多特性。
- **水果示例（共享属性）**：苹果和香蕉各不相同，但二者都**是**水果，所以凡对水果成立的，对它们也成立。所有水果都有名称、颜色、大小，并且会成熟——苹果和香蕉就继承这些属性与行为。
- **层级（hierarchy）的定义**："层级是一张用来展示各个对象如何相互关联的图。" 大多数层级图要么展示随时间的变化（如 386 → 486 → Pentium），要么展示从一般到具体的分类。
- **层级示例**：生物分类阶元（界、门、纲、目、科、属、种）构成一张由一般到具体的层级；形状也有层级——正方形 → 矩形 → 四边形 → 形状，直角三角形 → 三角形 → 形状。
- **层级的方向与继承**：层级由上（一般）到下（具体）展开，"层级中的每一项都继承它上方各项的属性和行为"。
