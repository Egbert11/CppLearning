# 24.7 Calling inherited functions and overriding behavior

> 原文：https://www.learncpp.com/cpp-tutorial/calling-inherited-functions-and-overriding-behavior/

## 核心概念

- **派生类默认继承基类行为**：除非你做了改动，否则基类的成员在派生对象上都可用。
- **名字查找从派生类开始**：编译器先检查派生类中是否存在被调用名字的函数。
- **重载是"按类"考虑，而非"按继承体系"**：若名字在派生类中找到，则该类中所有同名重载都是候选；若派生类中没有这个名字，编译器沿继承链向上、重复同样的过程。
- **选择规则**："编译器会从**最派生、且至少有一个同名函数**的那个类中，选出最佳匹配的函数。"
- **可原样复用基类行为**：若派生类没有定义匹配的函数，就调用基类版本，因为派生版本根本不存在。
- **重新定义即改变行为**：在派生类中声明同名函数，就会改用该版本，于是各行为可以不同。
- **访问说明符不会随重新定义而继承**：被重新定义的函数使用它在派生类中所声明的访问说明符；基类里 private 的函数在派生类里可以是 public，反之亦然。
- **重新定义会隐藏基类版本**：想从派生函数里调用基类版本，需要用作用域解析运算符，比如在调用前加上基类名。
- **不加限定会自我递归**：没有作用域限定的话，调用会解析到当前类自己的函数，造成无限递归。
- **友元函数要另想办法**：基类的友元函数不是成员，作用域解析对它无效；改为用 `static_cast` 让派生对象临时"看起来像"基类。
- **新增一个重载会隐藏该名字的所有继承重载**：若派生类引入了某个名字的任一函数，重载决议时就不会再考虑基类中该名字的重载。
- **变通一（较差）**：在派生类里为每个想保留的基类重载写转发函数——纯样板代码，只是把调用转给基类。
- **变通二（更好）**：在派生类里使用 using 声明，把基类中该名字的所有函数都变得可见、并参与重载决议。

## 最佳实践

本节无独立的 Best practice / Warning / Author's note 框。最有指导意义的是源码内联注释：不加限定的调用会无限递归；派生类中新增一个重载会隐藏基类同名重载；转发函数可用但不美观。
