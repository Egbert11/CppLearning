# 7.3 Local variables

> 原文：https://www.learncpp.com/cpp-tutorial/local-variables/

## 核心概念

- **什么是局部变量**：在函数内部声明的变量，**包括形参**。没有单一属性定义"局部"，而是一组特征把局部变量与其它变量区分开。
- **作用域（scope）**：标识符在源代码中可被使用的区域。可用即"在作用域内（in scope）"，不可用即"在作用域外（out of scope）"。作用域在编译期确定，引用作用域外的标识符是编译错误。
- **块作用域（block scope）**：局部变量从定义处到包含它的块结束处都在作用域内。
- **形参与块作用域**：形参在文本上位于函数体之外，但对普通函数而言，其行为就好像属于函数体块的作用域。
- **同一作用域内名字唯一**：同一作用域里名字不能重复，否则该名字的每次使用都有歧义，编译失败。
- **存储期（storage duration）**：控制变量何时、如何被创建与销毁的规则；多数情况下存储期直接决定变量的生存期（lifetime）。
- **自动存储期（automatic storage duration）**：局部变量在定义处创建、在块结束时销毁，因此也叫"自动变量（automatic variables）"。
- **嵌套块**：局部变量可声明在内层块中，其作用域与生存期从定义处到内层块结束，在外层块中不可访问。
- **外层变量向内可见**：嵌套块属于外层块的作用域，故块外声明的变量可在块内使用（反向不成立）。
- **无链接（no linkage）**：链接决定不同作用域里的同名声明是否指向同一对象。局部变量无链接，每次声明都指向不同的对象。
- **作用域 vs 链接**：作用域管"一个标识符的声明在哪里可见"；链接管"多个同名声明是否指同一实体"。
- **限制作用域**：缩小变量作用域可减少"存活着的变量"数量，便于理解。若外层块后来需要该变量，则必须在外层块中声明——这是少数应当"提前声明"的情形。
- **不要为缩小作用域而制造块**：这样会让函数更长、更复杂，通常得不偿失；更好的工具是拆成独立函数。

## 最佳实践

- **Best practice**：Define variables in the most limited existing scope.（把变量定义在尽可能小的既有作用域中。）
- **Best practice**：Avoid creating new blocks whose only purpose is to limit the scope of variables.（避免仅为限制变量作用域而创建新块。）

## 测验

- **第 1 题**：编写程序，让用户输入一个较小的整数与一个较大的整数；若次序不对则交换它们并打印交换提示，最后输出较小值与较大值。解答见 [7-03-quiz1.cpp](7-03-quiz1.cpp)。
- **第 2 题**：说明作用域（scope）、存储期（duration）、生存期（lifetime）的区别，以及局部变量默认具有哪种作用域与存储期。
  - 解答：作用域 = 代码中能访问该变量的区域；存储期 = 变量的创建/销毁规则；生存期 = 创建与销毁之间实际的时间区间。局部变量默认具有**块作用域**（从定义处到块结束）与**自动存储期**（定义处创建、块结束销毁）。
