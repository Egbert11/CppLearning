# 7.12 Scope, duration, and linkage summary

> 原文：https://www.learncpp.com/cpp-tutorial/scope-duration-and-linkage-summary/

## 核心概念

**作用域（scope）总览**
- 标识符的**作用域**"决定该标识符在源码中可以在哪里被访问"。
- **块（局部）作用域**：从声明点起可访问到所在块末尾（含嵌套块）。涵盖局部变量、函数形参，以及在块内声明的程序自定义类型（枚举、类）。
- **全局作用域**：从声明点起可访问到文件末尾。涵盖全局变量、函数，以及在命名空间或全局作用域中声明的程序自定义类型。

**持久期（duration）总览**
- 变量的**持久期**"决定它何时被创建与销毁"。
- **自动持久期**：在定义点创建，块退出时销毁（局部变量、函数形参）。
- **静态持久期**：程序启动时创建，程序结束时销毁（全局变量、静态局部变量）。
- **动态持久期**：由程序员按需创建与销毁（动态分配的变量）。

**链接性（linkage）总览**
- **链接性**"决定在不同作用域中同一标识符的声明是否指向同一实体"（对象、函数、引用等）。
- **无链接**：对同一标识符的第二次声明指向一个独一无二的实体。涵盖局部变量，以及块内声明的程序自定义类型标识符（枚举、类）。
- **内部链接**：同一翻译单元内对同一标识符的声明指向同一个对象/函数。涵盖静态全局变量、静态函数、const 全局变量，以及匿名命名空间及其中的一切。
- **外部链接**：全程序任意位置对同一标识符的声明都指向同一个对象/函数。涵盖非静态函数、非 const 全局变量、extern const 全局变量、inline const 全局变量，以及命名空间。
- **规则**：具有外部链接的标识符若在多个 `.cpp` 中定义，通常因单一定义规则而触发"重复定义"链接错误。例外是"类型、模板，以及内联函数与变量"（后续讲解）。
- **规则**：函数默认外部链接，可用 `static` 关键字改为内部链接。

**前向声明（forward declaration）总览**
- 前向声明让你能访问另一文件中的函数或变量；被声明变量的作用域遵循通常规则（全局变量为全局作用域，局部为块作用域）。
- 函数前向声明：只有原型，没有函数体。
- 非 const 变量的前向声明必须**不初始化**。
- const 变量的前向声明必须**不初始化**。
- **不允许** `extern constexpr` 前向声明。
- constexpr 变量（隐式 const）可通过 const 前向声明来前向声明；但通过该声明它只被当作 const，而**不是** constexpr。

**存储类说明符（storage class specifiers）**
- 作为声明的一部分时，`static` 与 `extern` 被称为存储类说明符——它们设定标识符的存储持久期与链接性。
- 表中列出 4 个仍在用的说明符及两个已弃用的：
  - `extern`：静态或 thread_local 持久期，外部链接。
  - `static`：静态或 thread_local 持久期，内部链接。
  - `thread_local`：线程存储持久期。
  - `mutable`：即使所在类为 const，该对象仍可修改。
  - `auto`：自动存储持久期（C++11 起弃用）。
  - `register`：自动存储持久期并附寄存器提示（C++17 起弃用）。
- 注："存储类说明符"这一说法多见于正式文档。
