# 18.2 Introduction to iterators

> 原文：https://www.learncpp.com/cpp-tutorial/introduction-to-iterators/

## 核心概念

- **遍历很常见**：走遍一个数据结构是很常见的任务；前面章节已经展示过几种做法——带下标的 `for`/`while` 循环、指针加指针算术、范围 for 循环。
- **下标循环的不足**：当下标只被用来取元素时，写下标是多余输入；而且它要求容器能直接按下标访问元素（数组可以，链表这类不行）。
- **裸指针循环的不足**：指针算术冗长、对不熟悉其规则的人不易读；而且它只在元素连续存放于内存时可用（数组可以，链表、树、映射不行）。
- **范围 for 循环**：它的遍历机制被隐藏，却可用于数组、链表、树、映射等——因为它使用迭代器。
- **迭代器定义**：迭代器（iterator）是“一种用于遍历容器的对象”，沿途可访问每个元素。
- **多种迭代器类型**：一个容器可提供多种迭代器类型，例如从前往后的正向迭代器、从后往前的反向迭代器。
- **统一接口**：因为迭代器通常共享同一遍历接口（`operator++` 前进）和访问接口（`operator*` 取当前元素），所以能用一致方式遍历多种容器。
- **指针作为迭代器**：最简单的迭代器就是指针，可用于顺序存放于内存的数据。定义 begin（容器起点）与 end 标记；对数组，end 标记是“若再多一个元素会占据的位置”。指针在两者之间前进，解引用得到当前值。
- **标准库迭代器**：“所有标准库容器都直接支持迭代”。不必自己计算 begin/end，调用成员函数 `begin()` 和 `end()` 即可。
- **泛型函数**：`<iterator>` 头文件还提供 `std::begin` 和 `std::end`，可用于容器。
- **实际只需要四样东西**：起点、终点、`operator++`（移到下一元素或终点）、`operator*`（读取当前元素）；容器细节由迭代器处理。
- **`operator<` vs `operator!=`**：数值比较的循环条件优先用 `operator<`；对迭代器，则约定用 `operator!=` 判断是否到达终点。原因：有些迭代器类型不支持关系比较，而 `operator!=` 对所有迭代器都能工作。
- **范围 for 再探**：任何具备 `begin()`/`end()` 成员、或可用 `std::begin()`/`std::end()` 的类型都能用于范围 for；其内部会调用 `begin()` 和 `end()`。`std::array` 满足；C 风格定长数组通过 `std::begin`/`std::end` 可用；动态的或已退化的 C 风格数组不行，因为不存在针对它的 `std::end`（类型不再携带长度信息）。
- **循环之外**：迭代器也出现在 `std::sort` 等算法中，在标准库中随处可见。
- **迭代器失效（悬垂迭代器）**：与指针和引用一样，当迭代器所指元素被销毁或地址改变时，它会悬垂；这样的迭代器称为“失效（invalidated）”，使用它是未定义行为。
- **哪些操作会失效**：某些修改容器的操作——例如向 `std::vector` 添加元素——可能把元素移动到新地址，从而使现有迭代器失效。好的参考文档会注明哪些操作可能/会失效迭代器。
- **小心范围 for**：由于它内部使用迭代器，遍历期间不要做会使被遍历容器的迭代器失效的操作。
- **重新有效化**：失效的迭代器可以通过赋给它一个有效的迭代器（如 `begin()`、`end()`，或其它返回迭代器的函数结果）来修复。
- **`erase()` 的返回值**：`erase()` 返回指向被删元素之后那个元素的迭代器（若删的是最后一个则返回 `end()`），可用于修正使用了失效迭代器的代码。

## 最佳实践

- 本节原文没有 **Best practice** 或 **Author's note** 标注。相关 **Warning** / **Tip**：
  - **Warning（C++17 要求）**：本节示例使用 C++17 的“类模板实参推导（CTAD）”，即从初始化列表推导模板变量的模板实参。若编译器未启用 C++17，会报类似 “missing template arguments before 'arr'” 的错误；建议开启 C++17，或把推导写法改成显式模板实参（如用 `std::array<int, 7>` 代替裸 `std::array`）。
  - **Warning（计算 end 指针）**：可能想写成 `int* end{ &arr[std::size(arr)] };`，但这会产生未定义行为，因为 `arr[std::size(arr)]` 隐含地对数组末尾之后的一个元素做下标/解引用。应改用 `arr.data() + std::size(arr)` 的形式。
  - **Tip（`std::begin`/`std::end` 的位置）**：对 C 风格数组它们定义在 `<iterator>`；对支持迭代器的容器，它们定义在容器自己的头文件中（如 `<array>`、`<vector>`）。
  - **For advanced readers**：不使用指针算术的指针也能遍历某些非顺序结构——例如链表中每个元素用指针连向前一个元素，迭代可以沿这条链进行。
