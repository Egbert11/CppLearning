# 18.1 Sorting an array using selection sort

> 原文：https://www.learncpp.com/cpp-tutorial/sorting-an-array-using-selection-sort/

## 核心概念

- **排序（sorting）**：把数组中的所有元素按某种选定的顺序排列。
- **排序的动机**：日常中邮件可按收件时间显示、联系人可按字母顺序显示；有序数据对人类和计算机都更容易搜索。
- **无序查找 vs 有序查找**：在无序列表中找名字可能要检查每个元素；在有序列表中，一旦越过目标本应出现的位置，就能确定其余部分不含目标。
- **更好的有序查找算法存在**：一个简单算法能在一个含 1,000,000 个元素的有序数组中只用约 20 次比较就完成查找。
- **排序有成本**：排序相对昂贵；除非你会搜索很多次，否则可能不划算。
- **排序有时能让查找变得不必要**：在有序列表中，最高分就在第一个或最后一个位置。
- **排序的一般做法**：比较成对的元素，在满足选定准则时交换它们。
- **比较顺序与准则因算法而异**：不同算法的比较顺序不同，准则取决于升序还是降序。
- **交换元素**：使用 `<utility>` 头文件中的 `std::swap()`。
- **选择排序（selection sort）**：一种容易理解但相对慢的排序算法。
- **选择排序流程**：从下标 0 开始，在整段数组中找出最小值并与下标 0 交换，然后从下一个下标重复。
- **重复直到结束**：直到没有剩余元素为止；最后一次是元素与自身的冗余比较，所以可以提前一个元素停下。
- **实例**：`{ 30, 50, 20, 10, 40 }` 经连续交换变为 `{ 10, 20, 30, 40, 50 }`。
- **C++ 选择排序结构**：嵌套循环——外层选 `startIndex`，内层在剩余元素中找最小元素，`smallestIndex` 记录它。
- **调试提示**：在纸上用箭头跟踪 `startIndex`、`currentIndex`、`smallestIndex` 有助于理解。
- **排序字符串**：同一选择排序算法可用，只需把元素类型由 `int` 改为 `std::string`。
- **`std::sort`**：标准库排序函数，位于 `<algorithm>`，以 begin/end 迭代器调用；默认按 `operator<` 升序排序。
- **Quiz 1**：手动跟踪对 `{ 30, 60, 20, 50, 40, 10 }` 的选择排序过程（含末尾出现的自我交换）。
- **Quiz 2**：要改成降序，把比较由 `<` 改为 `>`，并把 `smallestIndex` 改名为 `largestIndex` 之类。
- **Quiz 3（冒泡排序 bubble sort）**：比较相邻的一对元素，需要时交换，使元素“冒泡”到末尾；重复直到有序。
- **Quiz 4（冒泡排序优化）**：不再重复检查已排好的尾部；若某一整轮没有发生交换则提前终止；并打印提前终止时的轮次。

## 最佳实践

- 本节原文没有 **Best practice** / **Author's note** / **Warning** 标注；仅提供了两条 **Hint**：
  - **Hint**：在纸上跟踪选择排序的三个下标（`startIndex` / `currentIndex` / `smallestIndex`）可以更直观地理解算法。
  - **Hint**：写冒泡排序时，注意“已排好的尾部不必再比较”以及“整轮无交换即已有序”这两个优化点。
