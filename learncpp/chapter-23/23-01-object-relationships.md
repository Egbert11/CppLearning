# 23.1 Object relationships

> 原文：https://www.learncpp.com/cpp-tutorial/object-relationships/

## 核心概念

- **现实世界充满模式与关系**：世界中有大量重复出现的"图案、关系与层级结构"，理解它们有助于我们理解对象如何运作。
- **以植物类比**：遇到一株陌生的植物，只要掌握"植物"这一抽象概念，就能认出花和叶；叶利用阳光，花则依赖植物本体存在。
- **抽象与实例化**：我们之所以能识别，是因为理解了"一般概念"，并把具体对象看作该概念的一个实例，从而由一般概念推断出对象的属性。
- **编程中的类似情形**：代码里同样存在重复出现的模式、关系与层级结构；支配现实对象的关系规律同样适用于我们编写的对象。
- **意义所在**：审视这些关系有助于提升代码**可复用性**，并写出**更具可扩展性**的类。
- **此前学过的内容**：用循环与函数处理重复任务，用枚举、结构体、类来创建特定类型的对象。
- **已见过的"层级"**：数组把多个元素组织成一个更大的结构；递归让函数调用自身的派生版本。
- **本节新重点**：以往内容都没有从编程角度强调"对象之间的关系"。
- **关系词汇**：现实中的关系各有名称——正方形"是一个（is-a）"形状；汽车"有一个（has-a）"方向盘；程序员"使用（uses-a）"键盘；花"依赖（depends-on）"蜜蜂；学生"是（member-of）"班级的一员；大脑"是（part-of）"身体的一部分。
- **映射到 C++**：上述每一种关系在 C++ 中都有有用的对应物。
- **本章范围**：本章讨论类之间的 part-of、has-a、uses-a、depends-on、member-of 关系，并附带一些不属于其他任何地方的零散主题。
- **后续章节范围**：接下来两章将通过继承与虚函数讨论"is-a"关系。
