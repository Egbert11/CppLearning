# 23.5 Dependencies

> 原文：https://www.learncpp.com/cpp-tutorial/dependencies/

## 核心概念

- **四种关系**：本系列已讲组合、聚合、关联，作者把"最简单的一种留到最后：依赖（dependencies）"。
- **依赖的日常含义**：口语上指一个对象为了某项特定任务而依赖另一个对象——例如脚受伤时只需要拐杖，花只在授粉/繁殖时依赖蜜蜂，其他时候并不依赖。
- **正式定义**：当"一个对象调用另一个对象的功能以完成某项特定任务"时，就存在依赖。
- **相对关联的强度**：它"是比关联更弱的关系"，但被依赖对象的改动仍可能破坏调用方功能。
- **方向**：依赖"永远是单向关系"。
- **经典例子 `std::ostream`**：打印到控制台的类会用到 `std::ostream`，但**仅**为此目的。
- **没有直接关系的依赖**：`Point` 与 `std::ostream` 没有直接关系，却因为 `operator<<` 用该流输出 `Point` 而依赖它；程序在调用处也依赖 `std::cout`。
- **依赖 vs 关联（C++ 视角）**：关联把与另一个类的直接或间接"链接"保留为成员——如 `Doctor` 持有 `Patient` 指针数组，或 `Driver` 持有其 `Car` 的整数 id；拥有者"总是知道"这个关联。
- **依赖为何不同**：依赖通常**不是**成员；被依赖对象通常"在需要时临时实例化"（如打开文件），或"作为参数传入函数"（如重载 `operator<<` 中的 `std::ostream`）。
- **幽默插曲**：课中插了一幅关于依赖的 xkcd 漫画；作者打趣说它展示的"其实是一个自反关联！"
