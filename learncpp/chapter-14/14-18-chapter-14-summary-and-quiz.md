## 本章知识速览

- **过程式 vs 面向对象编程**：前者以函数（"过程"）作用于传入的数据为中心；后者以把"属性与一组定义良好的行为"打包在一起的程序自定义类型为中心。
- **类不变式（class invariant）**：对象整个生命周期中必须成立的条件；被破坏时对象处于"无效状态"，可能引发未定义行为。
- **类（class）**：把数据与操作数据的函数组合起来的复合类型；类里的函数是**成员函数**，被调用的那个对象是**隐式对象**；其他函数称为非成员函数。若没有数据成员，优先用命名空间。
- **const 成员函数**：承诺不修改对象、也不调用非 const 成员；不修改状态的函数应设为 const，以便能作用于 const 对象。
- **访问级别 / 访问控制**：按类定义而非按对象。**public 成员**不受限（"公众"可访问）；**private 成员**只有同类其他成员能访问。
- **默认访问级别**：struct 成员默认 public；class 成员默认 private。private 成员使类型不再是聚合，故不能聚合初始化。建议私有成员加 `m_` 前缀。
- **访问说明符（access specifier）**：显式设置访问级别；struct 一般应避免使用。
- **访问函数**：简单的公共成员——**getter/accessor** 返回私有值；**setter/mutator** 修改私有值。
- **接口（interface）**：用户与之交互的公共成员（"public interface"）；**实现（implementation）**：成员变量加函数体。
- **数据隐藏 / 信息隐藏 / 数据抽象**：把接口与实现分离；**封装（encapsulation）**也常指此事，但含义有歧义（也可仅指把数据与函数打包）。
- **声明顺序建议**： public 成员放在前面，private 放在后面。
- **构造函数**：初始化类类型对象；非聚合类型需要匹配的构造函数。
- **成员初始化列表**：按声明顺序初始化成员；优于在构造函数体内赋值。
- **默认构造函数**：无参数或全部有默认值；未提供初始化器时使用。没有用户声明的构造函数时，编译器生成**隐式默认构造函数**。
- **委托构造函数 / 构造函数链**：一个构造函数可委托给同类另一个构造函数，但不能既委托又初始化。
- **临时对象（anonymous / unnamed object）**：没有名字、只在一个表达式期间存在。
- **拷贝构造函数**：用同类型的一个对象初始化另一个对象；未提供时会生成执行逐成员初始化的**隐式拷贝构造函数**。
- **as-if 规则**：只要可观察行为不变，编译器可自由优化；**拷贝消除（copy elision）**是例外，被跳过的拷贝构造调用称为"被消除（elided）"。
- **用户自定义转换**：在程序自定义类型之间转换的函数；可用于隐式转换的构造函数称为**转换构造函数**（默认所有构造函数都是）。
- **explicit**：阻止构造函数用作转换构造函数；这样的构造函数不能用于拷贝初始化、拷贝列表初始化和隐式转换。
- **指导原则**：默认把单实参构造函数设为 explicit；只有当转换在语义上等价且开销低时才考虑非 explicit（如 `std::string` 到 `std::string_view`）；绝不把拷贝/移动构造函数设为 explicit。
- **constexpr 成员**：成员函数（含构造函数）可以是 constexpr；C++14 起 constexpr 成员函数不再隐式为 const。

## 核心概念

本节为整章回顾，概念已并入上方"本章知识速览"。测验涉及的关键点：

- `Point2d` 需要两个构造函数（默认与两参数）以及一个 const 的 `print()`。
- `distanceTo()` 使用 `<cmath>` 的 `std::sqrt` 与两点距离公式。
- `Fraction` 的 `multiply()` 返回构造好的 `Fraction`，可链式调用 `.printFraction()`。
- 构造函数加 `explicit` 可阻止单值隐式转换。

## 最佳实践

- **Best practice**：默认把单实参构造函数设为 `explicit`；只有当隐式转换在语义上等价且开销低时才允许隐式转换；不要把拷贝/移动构造函数设为 explicit。

## 测验

1. **测验 1a**：写出 `Point2d` 类，包含两个默认为 `0.0` 的 double 成员 `m_x`、`m_y`，一个构造函数和一个 `print()`；使给定程序能编译并打印两个点。（解答见 [14-18-quiz1a.cpp](14-18-quiz1a.cpp)）
2. **测验 1b**：为 `Point2d` 增加 `distanceTo()`，接受另一个 `Point2d`，使用 `<cmath>` 的 `std::sqrt` 和距离公式计算距离。（解答见 [14-18-quiz1b.cpp](14-18-quiz1b.cpp)）
3. **测验 2**：把 13.10 课的 `Fraction` struct 改写成类，把所有函数改为非静态成员函数。（解答见 [14-18-quiz2.cpp](14-18-quiz2.cpp)）
   - 为什么把 `Fraction` 的构造函数设为 `explicit`？——**答**：它阻止从单个值隐式转换，避免出现 `f1.multiply(true)` 这类"胡话"。没有 `explicit` 时编译器会用转换构造函数；有了它则无可用转换，编译失败。
4. **测验 4（概念题）**：为什么把 `getFraction()` 与 `print()` 保留为非成员可能更好？——**答**：非成员的 `getFraction()` 允许"创建并初始化一步到位"，而不是先构造再调用成员；它还承载面向用户的提示。把 `print()` 做成非成员（通过访问函数取数据）可使其脱离类接口，只要接口稳定，类实现变化就无需回头修改 `print()`。
5. **测验 5（概念题）**：测验 1a 中 `Point2d` 的成员函数为什么应声明为 `const`？——**答**：`print()` 与 `distanceTo()` 都不修改对象状态，声明为 const 后可作用于 const 对象，也表明其承诺。
