# 19.5 Void pointers

> 原文：https://www.learncpp.com/cpp-tutorial/void-pointers/

## 核心概念

- **定义**：void 指针（也叫"泛型指针"，generic pointer）可以指向任意数据类型的对象，声明时以 `void` 作为指针的类型。
- **可接受任意被指类型**：同一个 void 指针变量可以先指向 `int`，再指向 `float`，再指向某个 struct 对象，等等。
- **不能直接解引用**：因为指针不知道自己指向什么类型，必须先转换成别的指针类型，才能对它做间接访问。
- **类型由程序员负责追踪**：void 指针不携带类型信息，开发者必须自己记住它实际指向什么，才能正确转换。
- **一个分发示例**：一个接收 `void*` 与 `enum class Type` 标签（`tInt`、`tFloat`、`tCString`）的函数，按标签分支并转换成对应指针类型来打印值；C 字符串分支不做间接访问，以便 `std::cout` 把 `char*` 当作 C 风格字符串。
- **可以为空**：void 指针可用 `nullptr` 初始化。
- **删除 void 指针是未定义行为**：若需删除，先用 `static_cast` 转换回正确类型。
- **不能做指针算术**：void 指针上无法做算术运算，因为加减需要知道被指对象的大小才能正确前进/后退。
- **没有 void 引用**：指向 void 的引用会写成 `void&`，它无从得知被引用对象的类型，因此不存在。
- **结论 / 一般建议**：void 指针绕过了类型检查，除非确有需要，否则应避免使用。编译器不会阻止无意义的用法——例如把 `int` 指针却按 C 字符串标签传入，能编译但行为不可知。
- **更好的替代**：函数重载能处理多种数据类型并保留类型检查；模板在当年用 void 指针的许多场合已成为首选，同样提供强类型检查。
- **测验答案**：void 指针描述的是指针的**类型**（可指向任意对象，间接访问前必须显式转换）；空指针描述的是指针的**值**（不指向任何东西）。void 指针**可以**是空指针——两个概念彼此正交。

## 最佳实践

- 本节没有 "Best practice" / "Author's note" / "Warning" 框。最接近的是 **Conclusion**：尽可能避免使用 void 指针，先检查是否有更安全的替代方案；处理多种类型时优先用函数重载或模板。

## 测验

**Quiz #1**：什么是 void 指针？什么是空指针？void 指针可以是空指针吗？

- 答案：void 指针是一种指针**类型**，可指向任意数据类型的对象，解引用前必须显式转换；空指针是一种指针**值**，不指向任何对象。void 指针完全可以是空指针——"类型"与"值"是两个正交概念。
