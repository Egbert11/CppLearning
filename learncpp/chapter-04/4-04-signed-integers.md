# 4.4 Signed integers

> 原文：https://www.learncpp.com/cpp-tutorial/signed-integers/

## 核心概念

- **整数定义**：整数（integer）是能表示正整数、负整数以及 0 的整型（如 −2、−1、0、1、2）。
- **四种主要整数类型**：`short int`（最小 16 位）、`int`（最小 16 位，现代系统常为 32 位）、`long int`（最小 32 位）、`long long int`（最小 64 位）。
- **类型间的差别**：主要在于大小，越大的类型能容纳越大的数值。
- **最小尺寸提醒**：C++ 只保证整数的最小尺寸，而非精确尺寸（确定实际大小见 4.3）。
- **旁注**：`bool` 与 `char` 技术上也是整型（以整数存储），但不在本节的讨论范围内。
- **符号（sign）**：一个数是正、是负还是零，这个属性称为该数的符号。
- **默认有符号**：C++ 中整数默认是 signed（有符号），即符号是存储值的一部分，因此可表示正数、负数与 0。
- **首选简写**：优先使用简写类型名，而非带 `int` 后缀的形式——少打字，也避免与普通 `int` 混淆。
- **冗余的 `signed` 关键字**：整数可以显式写 `signed`，但应避免，因为有符号本就是默认行为。
- **范围（range）**：一个数据类型所能容纳的具体取值的集合，由位数及是否有符号决定。
- **8 位示例**：8 位有符号整数安全存储 −128 到 127（含两端）。
- **范围表**：
  | 大小 | 范围 |
  |---|---|
  | 8 位 | −128 到 127 |
  | 16 位 | −32,768 到 32,767 |
  | 32 位 | −2,147,483,648 到 2,147,483,647 |
  | 64 位 | −9,223,372,036,854,775,808 到 9,223,372,036,854,775,807 |
- **一般公式**：n 位有符号变量范围是 −(2^(n−1)) 到 (2^(n−1))−1。
- **进阶——补码（two's complement）**：以上范围基于补码表示，它是事实标准，且自 C++20 起被强制要求。旧标准还允许符号-数量级（sign-magnitude）与反码（ones' complement），其范围不同。
- **溢出（overflow）定义**：C++20 标准称，若结果“在数学上未定义，或不在该类型可表示的值范围内”，则行为未定义；这被俗称为 overflow。
- **赋予越界值**：把 140 放进 8 位有符号整数是未定义行为，因为 140 需要 9 位（或说需要比可用更多的数值位）。
- **算术/整数溢出**：当加法或乘法等运算产生超出可表示范围的结果时，称为整数溢出（integer overflow）或算术溢出；对有符号整数而言是未定义行为。
- **无符号溢出**：在 4.5 单独讲解。
- **信息丢失**：溢出一般会丢失信息，这几乎总是我们不想要的；如果某值可能超出类型范围，应改用范围更大的类型。
- **整数除法**：两个整数相除，结果仍是整数；小数部分被丢弃，而非四舍五入。
- **除法示例**：`8 / 5` 得 1（因为 1.6 被截断）；`−8 / 5` 得 −1。商会是可预测的，但会丢失小数部分。
- **Quiz 答案**：5 位有符号整数范围 −16 到 15；`13 / 5` 得 2；`−13 / 5` 得 −2。

## 最佳实践

- 优先使用不带 `int` 后缀、不带 `signed` 前缀的简写类型。
- 注意：使用整数除法时会丢失商的小数部分；若这正是你想要的行为，它是安全且可预测的。
