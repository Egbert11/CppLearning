# 4.1 Introduction to fundamental data types

> 原文：https://www.learncpp.com/cpp-tutorial/introduction-to-fundamental-data-types/

## 核心概念

- **变量就是一段内存**：定义变量时，会为其在内存（RAM）中留出一块区域，变量名就是这段区域的名字。
- **bit（位）**：最小的内存单位，即 binary digit，只能存 0 或 1——像只能全开或全关的开关，没有中间状态。
- **内存地址**：内存按顺序被划分为带编号的单元，即内存地址（address）。借助地址可以定位并取出某个位置的内容，如同用门牌号找到一栋房子。
- **地址粒度规则**：现代架构并不给每个 bit 单独编址，而是**一个地址对应一个字节**。原因是地址数量有限，且极少需要按位访问。
- **字节（byte）**：作为一组处理的若干位；现行标准规定一个字节为 8 个连续 bit。C++ 中处理数据通常以“字节大小”的块为单位（Key insight）。
- **旁注**：老旧或非标准硬件上字节可能是 1~48 位，但现代事实标准是 8 位，本系列教程假定 8 位字节。
- **数据类型的作用**：内存里只是 bit 序列，本身没有意义。data type（类型）告诉编译器如何解释这些 bit——例如声明为整数，就表示这段内存要按整数解读。
- **赋值时编码**：给对象赋值时，编译器与 CPU 把该值转换成对应类型的 bit 模式（原文举例：整数值 `65` 被编码为 `0100 0001`）。
- **求值时解码**：对对象求值时，再把 `0100 0001` 还原为 `65`。这些转换由编译器与 CPU 完成，程序员无需手动处理。
- **实用规则**：使用者只需选择行为最符合需求的类型即可。
- **基本数据类型**：语言预定义了许多类型，其中最基础的一类叫 fundamental data types，非正式也叫 basic types 或 primitive types。
- **基本类型一览表**：
  | 类别 | 类型 | 含义 | 示例 |
  |---|---|---|---|
  | 浮点 | `float`、`double`、`long double` | 带小数部分的数 | `3.14159` |
  | 整型-布尔 | `bool` | 真或假 | `true` |
  | 整型-字符 | `char`、`wchar_t`、`char8_t`(C++20)、`char16_t`(C++11)、`char32_t`(C++11) | 单个文本字符 | `'c'` |
  | 整型-整数 | `short int`、`int`、`long int`、`long long int`(C++11) | 可正可负的整数（含 0） | `64` |
  | 空指针 | `std::nullptr_t`(C++11) | 空指针 | `nullptr` |
  | 空 | `void` | 无类型 | — |
  本章会讲解除 `std::nullptr_t`（留到指针部分）之外的全部类型。
- **integer 与 integral**：数学上 integer 没有小数部分；C++ 中 integral 意为“像整数的”。
  - **标准整数类型（standard integer types）**：`short`、`int`、`long`、`long long` 及其 signed/unsigned 变体。
  - **整型（integral types）**：`bool`、字符家族，以及标准整数类型。
- **输出行为**：所有 integral 类型都以整数值存储，但只有标准整数类型会按整数打印；`bool` 与字符类型如何显示在各自小节讲解。
- **术语辨析**：标准把 “integer types” 当作 “integral types” 的同义词，但日常用法常仅指标准整数类型。另外 integral types 只涵盖基本类型，因此 `enum` 与 `enum class` 不算（尽管它们底层也以整数存储）。
- **三类类型**：① 基本数据类型（最基础）；② 复合数据类型（更复杂，可自定义类型，见 12.1）；③ 标准库类型（数量最大，随 C++ 发行版提供，需要相应头文件并链接库）。前两者内建于语言，无需头文件。
- **命名警告**：“built-in type” 通常指基本类型，但 Stroustrup 等人也用它涵盖复合类型，该词没有严格定义，建议避免使用。
- **字符串缺席**：没有基本类型用于表示字符串（文本），因为现代 C++ 把字符串放进标准库（见 5.7）。
- **`_t` 后缀**：许多较新类型（如 `std::nullptr_t`）带 `_t` 后缀，代表 “type”。见到它通常说明是个类型，但很多类型并不带，因此该规则并不一致。
