# 4.7 Introduction to scientific notation

> 原文：https://www.learncpp.com/cpp-tutorial/introduction-to-scientific-notation/

## 核心概念

- **科学计数法的用途**：它是一种紧凑书写很长或很小数值的方式。理解它有助于解释浮点数的工作原理以及浮点数的局限。
- **数的形式**：写成“有效数字(significand) × 10^指数(exponent)”。例如 `1.2 x 10^4` 中，`1.2` 是有效数字，`4` 是指数，它等于 12000。
- **书写约定**：小数点前只保留一位数字，其余有效数字放在小数点之后。
- **对大/小数值的好处**：地球质量约 5,972,200,000,000,000,000,000,000 kg，写成 `5.9722 x 10^24 kg` 更易读；比较量级时只比较指数即可。
- **C++ 记法**：由于指数不好输入，C++ 用字母 `e`（或 `E`）代替“×10 的幂”，例如 `1.2e4`、`5.9722e24`。
- **负指数**：用于表示小于 1 的数。`5e-2` 等于 5 / 10^2，即 `0.05`。电子质量约 `9.1093837e-31 kg`。
- **有效数字(significant digits / significant figures)**：指 `e` 之前有效数字里的位数；位数越多，数值越精确。`3.14` 可写成 `3.14e0`（3 位有效数字），`3.14159e0` 有 6 位。
- **转换步骤**：指数先设为 0；没有小数点的数视为在右端有一个小数点；移动小数点使左边只剩一个非零数字；小数点左移则指数 +1，右移则指数 −1；去掉前导零；只有原数没有小数点时才去掉末尾的零。
- **小数点后的末尾零**：视为有效数字，予以保留。`87.0` → `8.70e1`；`87.000` → `8.7000e1`。
- **整数末尾的零**：默认视为不显著而丢弃，`2100` → `2.1e3`；若确知该数是被精确测量的，则保留，`2100` → `2.100e3`。
- **显式的末尾小数点**：`2100.` 表示前面的零是有效数字，写成 `2.100e3`。
- **一致性与技术说明**：科学计数法总能明确显示有效数字个数。但在 C++ 里 `87.0`、`87.000` 的值和类型完全相同，内存中只存 87，无法再从内存还原原来的精度。

（原文给出的换算示例：`600.410` → `6.00410e2`（6 位有效数字）；`0.0078900` → `7.8900e-3`（5 位）；`42030`（末尾零不显著）→ `4.203e4`（4 位）；`42030`（末尾零显著）→ `4.2030e4`（5 位）。）

## 最佳实践

> Tip：一个数若带有显式的末尾小数点，表示它前面的零都算有效数字；`2100.` 应写成 `2.100e3`。
>
> Key insight：有效数字的位数越多，数值就越精确。
