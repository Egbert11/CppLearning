# 13.10 Passing and returning structs

> 原文：https://www.learncpp.com/cpp-tutorial/passing-and-returning-structs/

## 核心概念

- **松散变量的扩展性差**：把一名员工拆成 `int`/`double` 等独立变量，必须一个成员一个成员地传递，"既费时又易错"；新增字段还得改遍每个函数声明、定义与调用。
- **结构体一般按引用传递**：教程指出 struct "一般按引用传递（通常按 const 引用）以避免拷贝"。
- **一个参数搞定任意多成员**：因为整个对象作为一个整体传递，只需一个参数；以后新增成员也无需改动函数签名或调用点——新成员自动包含在内。
- **临时（无名）结构体**：临时对象"不是变量，因此没有标识符"，可以在一条语句中创建并使用结构体。
- **两种临时对象语法**：显式写出类型（如 `Employee { 14, 32, 24.15 }`）被推荐，因为它无歧义；只写花括号（如 `{ 15, 28, 18.27 }`）依赖编译器把参数隐式转换为 `Employee`。
- **隐式 vs 显式转换**：裸花括号形式属于隐式转换，因此在只允许显式转换的场合会失败。
- **临时对象的生命周期与值类别**：临时对象在其定义点被创建并初始化，在**完整表达式结束时销毁**；它们是右值表达式，只能绑定到接受右值的形参——按值传递、按 const 引用传递可以，按非 const 引用传递、按地址传递则不行。
- **函数只返回一个值——struct 打包多个**：一个 3D 点（x、y、z）可作为一个 struct 一次返回。
- **按值返回，而非按引用**："函数内部定义的结构体通常按值返回，以免返回悬垂引用。"
- **优先返回无名对象**：不要先建一个具名局部变量再返回它，直接返回一个临时对象更简洁（"一行 vs 两行"）。
- **返回语句中可省略类型**：当返回类型已显式写出（如 `Point3d`）时，`return { 0.0, 0.0, 0.0 };` 可行，且算作隐式转换。
- **空花括号值初始化**：`return {};` 返回一个被值初始化的结构体。
- **struct 是构建块**：类（class）"直接构建在本文引入的概念之上"，尤其是数据成员、成员选择和默认成员初始化。

## 最佳实践

本节无 Best practice / Rule / Warning 条目。仅在代码注释中把"显式写出类型的临时对象形式"标为 preferred（更优）。
