# 13.7 Introduction to structs, members, and member selection

> 原文：https://www.learncpp.com/cpp-tutorial/introduction-to-structs-members-and-member-selection/

## 核心概念

- **问题**：有些事情需要一次用上好几个变量——比如分数的分子与分母，或员工的名字、职位、年龄、工号、工资、生日/入职日期。
- **为什么独立变量不行**：看不出这些变量彼此相关；要追踪的变量太多；把员工传给函数需要一长串有顺序的参数；函数只能返回一个值；每多一个员工就要一整套新的、唯一命名的变量——这种扩展难题正是复合类型的动机。
- **结构体的定义**：struct 是一种程序自定义数据类型，把多个变量打包成一个类型。C++ 提供了 struct 和 class 来做这件事。
- **提醒（类类型）**：struct 属于类类型，就像 class 和 union 一样，因此适用于类类型的规则也适用于 struct。
- **必须先定义后使用**：因为 struct 是程序自定义的，编译器必须先看到它的定义才能使用该类型。
- **`struct` 关键字与命名**：`struct` 关键字引入定义；按惯例程序自定义类型名以大写字母开头。
- **数据成员**：花括号里声明的那些变量就是该结构体的数据成员（也叫成员变量）。
- **Tip（什么是成员）**：成员是隶属于 struct 或 class 的变量、函数或类型；每个成员都必须在该 struct/class 的定义里声明。这个术语在后续课程中大量出现。
- **值初始化**：每个成员后面的空花括号 `{}` 表示创建对象时该成员会被值初始化（13.9 节 "Default member initialization" 会进一步讲解）。
- **分号**：类型定义以分号结尾。定义本身不创建任何对象。
- **定义对象**：通过定义该类型的变量来使用它，如 `Employee joe {};`——对象被实例化，包含全部成员，空花括号将其值初始化。同一种 struct 类型可以定义多个变量。
- **访问成员**：成员选择运算符（`operator.`）放在结构体变量名和成员名之间——如 `joe.age`。
- **成员与普通变量一样**：对成员做赋值、算术、比较、自增都可以。
- **结构体的好处**：每个 struct 变量只需一个新名字（成员名由类型固定），同类型的多个对象拥有一致的成员名，一致而有序。
- **下一节**：结构体的初始化见 13.8 "Struct aggregate initialization"。

## 最佳实践

本节无 Best practice / Warning 条目。仅有：

- **A reminder**：struct 是一种类类型（class、union 同样是）。因此适用于类类型的规则也适用于 struct。
- **Tip（定义成员）**：在 C++ 中，成员是隶属于 struct 或 class 的变量、函数或类型，所有成员都必须在该定义内部声明。这个术语在后续课程中频繁出现。
