# 5.2 Literals

> 原文：https://www.learncpp.com/cpp-tutorial/literals/

## 核心概念

- **字面量（literals）**：直接写在源代码里的值，如 `5`、`true`、`3.4`、`"Hello, world!"`。也叫字面量常量（literal constants），因为其含义不可被重新定义。
- **每个字面量都有类型**：类型由值本身推导，例如整数 `5` 推导为 `int`。
- **默认字面量类型**：
  | 字面量种类 | 示例 | 默认类型 | 备注 |
  |---|---|---|---|
  | 整数 | `5, 0, -3` | `int` | |
  | 布尔 | `true, false` | `bool` | |
  | 浮点 | `1.2, 0.0, 3.4` | `double` | 不是 float！ |
  | 字符 | `'a', '\n'` | `char` | |
  | C 风格字符串 | `"Hello, world!"` | `const char[14]` | 见下文 |
- **后缀可改变字面量类型**（当不想要默认类型时）：
  | 数据类型 | 后缀 | 含义 |
  |---|---|---|
  | 整型 | `u` / `U` | unsigned int |
  | 整型 | `l` / `L` | long |
  | 整型 | `ul` / `uL` / `Ul` / `UL` / `lu` / `lU` / `Lu` / `LU` | unsigned long |
  | 整型 | `ll` / `LL` | long long |
  | 整型 | `ull` / `uLL` / `Ull` / `ULL` / `llu` / `llU` / `LLu` / `LLU` | unsigned long long |
  | 整型 | `z` / `Z` | std::size_t 的有符号版本（C++23） |
  | 整型 | `uz` / `uZ` / `Uz` / `UZ` / `zu` / `zU` / `Zu` / `ZU` | std::size_t（C++23） |
  | 浮点 | `f` / `F` | float |
  | 浮点 | `l` / `L` | long double |
  | 字符串 | `s` | std::string |
  | 字符串 | `sv` | std::string_view |
- **后缀通常不必要**，`f` 是主要例外；`s` 与 `sv` 需要额外一行代码才能使用（见 5.7、5.8）。
- **后缀大小写规则**：多数后缀忽略大小写，但 `s` 与 `sv` 必须小写，且连续两个 `l`/`L` 必须大小写一致（`lL`、`Ll` 会被拒绝）。
- **整数字面量**一般不需要后缀：普通 `int` 字面量可以用来初始化其他整型，编译器会自动转换。
- **浮点字面量默认是 `double`**：加 `f`/`F` 才得到 `float` 字面量。
- **常见新手坑**：`float f { 4.1 };` 会告警，因为 `4.1` 是 `double` 字面量而非 `float` 字面量。编译器不看字面量被用在何处，`double`→`float` 可能丢失精度，所以报出转换警告。
- **科学计数法**：浮点字面量可用标准写法（带小数点），也可用带 `e` 指数的写法（e 表示 10 的幂）。
- **字符串（string）**：用于表示文本的字符序列；字符串字面量用双引号，字符字面量用单引号。
- **C 风格字符串**：出于历史原因字符串不是基本类型，它继承了复杂的类型，称为 C 字符串 / C 风格字符串。
- **隐藏的空终止符**：每个 C 风格字符串字面量结尾都隐含一个 `'\0'`。`"hello"` 看似 5 个字符，实际有 6 个，最后是空终止符；以这种方式结尾的字符串称为以空字符结尾的字符串（null-terminated string）。
- **类型长度的由来**：这就是 `"Hello, world!"` 的类型是 `const char[14]` 而非 `const char[13]` 的原因——隐藏的终止符也算一个字符。
- **C 风格字符串字面量是对象**：它们是程序启动时创建的 `const` 对象，保证在整个程序生命周期内存活（这一点后面对 `std::string_view` 很重要）。
- **临时字符串对象**：与 C 风格字符串字面量不同，`std::string` 与 `std::string_view` 字面量创建的是临时对象，必须在当前完整表达式内立即使用，因为它们在表达式结束时会销毁。
- **魔法数字（magic number）**：含义不清、或将来可能需要改动的字面量（通常是数值）。
- **为什么魔法数字不好**：它不提供上下文；要改值时必须找出所有相关出现位置，而全局查找替换又可能误改恰好同数字的字面量，既费时又易错。
- **解决办法——符号常量（symbolic constant）**：给值起名字，既提供上下文，又只有一个修改点。魔法值也可能是非数值，比如应用名文本。
- **并非所有字面量都是魔法数字**：上下文显而易见、且不太可能改变的字面量通常不算，例如 `-1`、`0`、`0.0`、`1`、明显的换算系数 `1000`、以及顺序编号/计数。

## 最佳实践

- 字面量后缀优先使用大写 `L`，而非小写 `l`。
- 避免代码中的魔法数字（改用 `constexpr` 变量，见 5.6）。
