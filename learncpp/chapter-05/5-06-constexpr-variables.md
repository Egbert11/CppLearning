# 5.6 Constexpr variables

> 原文：https://www.learncpp.com/cpp-tutorial/constexpr-variables/

## 核心概念

- **`const` 用作编译期常量的局限（回顾）**：只有**整型**、且初始化器是常量表达式的 `const` 变量才能用在常量表达式中；其他情况都不行。用 `const` 承担这个职责有几个缺点。
- **缺点一：看不出一段 `const` 变量是否能用于常量表达式**。简单情形一眼可辨，但若初始化器来自另一个变量或一次函数调用，就必须回溯初始化器的定义才能确定。
- **缺点二：无法强制要求编译期常量**。`const` 不能在值不是常量表达式时让编译失败，它只是悄悄生成一个运行期常量。
- **缺点三：非整型没有编译期常量**。`const` 无法为非整型（如 `double`）提供编译期常量，而这往往正是我们想要的。
- **`constexpr` 关键字**：是 "constant expression"（常量表达式）的缩写，用来替代声明中的 `const`。`constexpr` 变量**永远**是编译期常量，因此必须用常量表达式初始化，否则编译报错。
- **函数与 `constexpr`**：函数通常在运行期执行，所以函数的返回值不是 constexpr（即便返回表达式是常量表达式）；这正是 `five()` 之类的调用不能用来初始化 `constexpr` 变量的原因（完整讲解见 F.1）。
- **非整型也可用 `constexpr`**：例如 `constexpr double` 可以用于常量表达式。
- **`const` 与 `constexpr` 对变量的含义**：
  - `const`：初始化后值不可改；初始化器可在编译期或运行期确定；对象可以只在运行期求值。
  - `constexpr`：对象可用于常量表达式；初始化器必须编译期已知；对象可在运行期或编译期求值。
- **隐式限定符**：`constexpr` 变量隐式地是 `const`；而 `const` 变量不隐式地是 `constexpr`（例外：初始化器是常量表达式的 `const` **整型**）。同时写 `constexpr const` 通常冗余。
- **`constexpr` 不是对象类型的一部分**：由于对象会隐式获得 const，`constexpr int` 变量的实际类型其实是 `const int`。
- **与类型兼容性的注意点**：有些类型不能完全支持 constexpr，包括 `std::string`、`std::vector` 等使用动态内存分配的类型。这类常量对象要么用 `const`，要么改用 `std::string_view`、`std::array` 等支持 constexpr 的类型。
- **命名由来**："constexpr" 是 "constant expression" 的合成词，因为 constexpr 对象与函数可用于常量表达式。严格说该关键字只作用于对象和函数；口头上常泛指任何常量表达式（如 `1 + 2`）。
- **进阶背景（数组长度）**：数组声明要求长度编译期已知，以便编译器分配内存。C++ 曾为"初始化器是常量表达式的 const 整型"开了特例，使其可作数组长度。C++11 引入常量表达式时保留了这一旧行为，并决定不扩展到其他类型。
- **const / constexpr 与函数参数**：运行期的实参用来初始化形参，因此 const 形参是运行期常量（即便实参是编译期常量）；而形参本身不能声明为 constexpr，因为它的初始值到运行期才确定（向函数传递编译期常量见 11.9 非类型模板参数）。
- **术语速记**：
  - *编译期常量*：值或不可修改对象，其值必须在编译期已知（如字面量、constexpr 变量）。
  - *Constexpr*：把对象声明为编译期常量的关键字（也用于可编译期求值的函数）；口头上是"常量表达式"的简写。
  - *常量表达式*：只含编译期常量、以及支持编译期求值的运算符/函数的表达式。
  - *运行期表达式*：不是常量表达式的表达式。
  - *运行期常量*：不是编译期常量的值或不可修改对象。
- **constexpr 函数简介**：constexpr 函数可用于常量表达式。当它所属的常量表达式必须编译期求值时，它就在编译期求值；否则可在编译期或运行期求值。要能编译期执行，所有实参都必须是常量表达式。`constexpr` 关键字写在声明中、返回类型之前。

## 最佳实践

- **Best practice**：任何初始化器是常量表达式的常量变量，都应声明为 `constexpr`。
- **Best practice**：任何初始化器不是常量表达式（即运行期常量）的常量变量，都应声明为 `const`。
