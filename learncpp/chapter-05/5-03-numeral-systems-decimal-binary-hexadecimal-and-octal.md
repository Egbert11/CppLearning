# 5.3 Numeral systems (decimal, binary, hexadecimal, and octal)

> 原文：https://www.learncpp.com/cpp-tutorial/numeral-systems-decimal-binary-hexadecimal-and-octal/

## 核心概念

- **十进制（decimal，base 10）**：使用 0–9 十个数字，是日常生活的计数系统。C++ 程序里的数字默认就是十进制。
- **二进制（binary，base 2）**：只用 0 和 1。较长的二进制值常按每四位一组、用空格分开书写，例如 `1101 0100`。
- **数制（numeral system）**：用来表示数字的一组既定符号（数字）。
- **C++ 中的四种主要数制**（按流行度排序）：十进制(10)、二进制(2)、十六进制(16)、八进制(8)。
- **命名规则**：十进制与二进制里符号 0 和 1 含义相同，但 `10` 在不同数制中值不同，所以“十”（ten）这个名字只保留给十进制；其他数制里应读作“一零”“一一”等。二进制 101 读作“一零一”，而不是“一百零一”。
- **八进制（octal，base 8）**：数字为 0–7，计数会 …7, 10, 11… 跳过 8 和 9。字面量以 `0` 开头。很少使用，建议避免。
- **十六进制（hexadecimal，base 16）**：数字 0–9 再加 A–F（也允许小写，但大写更常见）。字面量以 `0x` 为前缀（也可写 `0X`，但为可读性通常用小写）。
- **所有数制共用的计数模式**：最右位从 0 增到 base−1；到达 base 时归 0，并向左邻位进一，必要时继续向左进位。
- **十六进制与二进制的关系**：一位十六进制正好覆盖 4 个 bit，因此两位十六进制可表示一个完整字节（8 bit）。例：二进制 `0011 1010 0111 1111 1001 1000 0010 0110` 对应十六进制 `3A7F 9826`。
- **为什么用十六进制**：它能简洁地表示内存地址，以及类型未知的原始内存数据。
- **C++14 之前的二进制字面量**：语言不支持，常用十六进制字面量作为替代写法（在老代码中很常见）。
- **C++14 起的二进制字面量**：使用 `0b` 前缀。
- **数字分隔符（C++14）**：可在字面量中插入单引号 `'` 用于视觉分组，不改变数值；但不能出现在第一个数字之前。
- **输出进制控制**：`std::dec`、`std::oct`、`std::hex` 操纵符可改变输出进制；十进制是默认值。操纵符会持续对后续输出生效，直到被再次改变。
- **二进制输出**：`std::cout` 没有内建的二进制输出；可用 `<bitset>` 中的 `std::bitset`，需指定一个编译期常量作为位数，它可从任意整型格式初始化。
- **C++20/C++23 的替代方案**：Format 库（`<format>`）与 Print 库（`<print>`）支持用 `{:b}` 与 `{:#b}` 做二进制格式化。
- **测验答案**：十进制 32 的二进制是 `10 0000`，十六进制是 `20`。
