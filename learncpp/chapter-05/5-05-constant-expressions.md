# 5.5 Constant expressions

> 原文：https://www.learncpp.com/cpp-tutorial/constant-expressions/

## 核心概念

- **默认在运行期求值**：表达式通常在程序运行时求值；有些表达式必须如此，因为输入/输出无法在编译期发生。
- **as-if 规则**：当值已经已知时，编译器可以自行决定某些表达式是运行期求值还是编译期求值。
- **有些上下文要求编译期求值**：例如 `constexpr` 变量的初始化式。若没有提供常量表达式，“编译器会报错并停止编译”。
- **进阶：要求编译期可求值表达式的上下文**：`constexpr` 变量的初始化式、非类型模板实参、`std::array` 或 C 风格数组的定义长度。
- **为什么要显式（编译期编程）**：as-if 规则是不可见的，且依赖平台、编译器与编译选项，你无法得到“哪些被提前求值”的反馈。
- **好处**：性能（程序更小更快）、通用性（可用于要求编译期值的地方）、可预测性（缺失时报硬错误，而非静默改为运行期）、质量（编译器能检出错误；编译期不允许未定义行为）。
- **基础特性**：constexpr 变量、constexpr 函数、模板、`static_assert`，它们都用到常量表达式。
- **常量表达式（constant expression）的定义**：“由字面量、常量变量、运算符和函数调用构成的一段非空序列，其中每一部分都必须在编译期可求值。”关键在于*每一部分*都要满足。
- **Key insight**：在常量表达式中，表达式的每一部分都必须在编译期可求值。
- **非常量表达式 / 运行期表达式**：任何不是常量表达式的表达式；这类表达式通常在运行期求值。
- **延伸阅读**：C++20 标准 [expr.const] 说常量表达式可在翻译（translation）期间求值；对已编译的程序而言，即在构建（build）期间。
- **常量表达式里允许出现的内容**：字面量；操作数为常量表达式的大多数运算符；以常量表达式初始化的 `const` 整型变量（一个“历史遗留例外”）；constexpr 变量；以常量表达式为实参的 constexpr 函数调用。
- **进阶：额外允许的项目**：非类型模板形参、枚举量、类型特征（type traits）、constexpr lambda。
- **禁止出现的内容**：非常量变量；即使初始化式是常量表达式的 const 非整型变量；非 constexpr 函数的返回值；函数形参；操作数不是常量表达式的运算符；以及 `new`、`delete`、`throw`、`typeid`、`operator,` 等运算符。
- **命名**：“X 可用于常量表达式”强调实体；“X 是常量表达式”强调整段表达式。
- **历史旁注**：`const` 整型是被“祖父条款”保留下来的；委员会选择不把这一例外扩展到 `const` 非整型，以鼓励统一使用 `constexpr`。
- **何时编译期求值是强制的**：只在对常量表达式有*要求*的上下文里。其技术术语是 manifestly constant-evaluated expression（明显常量求值表达式）。
- **Key insight**：编译器*只需*在*要求*常量表达式的上下文里于编译期求值常量表达式；其他情况下它可做可不做。
- **小贴士——完全编译期求值的可能性**：Never（编译器无法完全解析的非常量表达式）；Possibly（可解析的非常量表达式，可经 as-if 规则优化）；Likely（处于非要求上下文的常量表达式）；Always（处于要求上下文的常量表达式）。
- **进阶：为什么不总是要求编译期求值**：编译期求值更难调试（诊断工具有限），且这样做保留了编译器的灵活性，例如为改善构建时间而推迟求值。
- **可选阅读——为什么编译期表达式必须是常量**：从用户输入重新赋值的变量，其值之后未知，因此不可能总在编译期求值；而常量永不改变，这让模型保持简单，并避免写出脆弱的程序。
- **测验**：8 项（a–h），判断每个初始化式、以及每个变量是否为常量表达式。

## 最佳实践

本节没有 Best practice / Warning 条目。相关提示：

- **Key insight**：常量表达式的每一部分都必须可在编译期求值。
- **Key insight**：编译期求值只在*要求*常量表达式的上下文中是强制的。
- **Tip**：禁止出现在常量表达式中的内容清单；Never / Possibly / Likely / Always 可能性分类。
- **Author's note**：常量表达式在技术上很复杂，不必强记其中大部分内容，因为当你需要常量表达式而未提供时，编译器会报错提醒你。
