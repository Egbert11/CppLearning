# 1.8 Whitespace and basic formatting

> 原文：https://www.learncpp.com/cpp-tutorial/whitespace-and-basic-formatting/

## 核心概念

- **空白的定义**：空白（whitespace）指用于排版目的的字符，在 C++ 中主要指空格、制表符和换行符，用途有三：分隔语言元素、出现在文本（字符串）内部、以及给代码排版。
- **必须分隔的场合**：某些语言元素之间必须有空白，主要是两个关键字或标识符紧挨在一起、编译器需要区分它们的时候（如 `int x;` 中的 `int` 与 `x`）。少了分隔，`intx` 会被当成一个标识符，编译器报“未知标识符”。
- **空白数量无关紧要**：只要存在空白即可，多少都行。`int x;`、`int                y;`、甚至把类型名和变量名分写在两行都合法。
- **换行也是一种分隔**：单行注释以换行结束，换行符之后的内容不再属于注释；预处理指令必须各占一行。
- **引号内是字面量**：字符串字面量内部的空白会被原样计数，`"Hello world!"` 与 `"Hello          world!"` 输出不同。
- **引号内不能换行**：字符串字面量内部不能出现真正的换行。
- **相邻字面量自动拼接**：仅由空白（空格、制表符或换行）分隔的多个字符串字面量会被合并成一个。
- **自由排版**：除此之外 C++ 忽略空白，可任意放置以提升可读性；一条语句也可以拆成多行，便于处理过长的语句。因此 C++ 被称为“与空白无关的语言”。
- **制表符 vs. 空格**：两者都可以（IDE 能把一次 Tab 转换成若干空格）；作者推荐 Tab = 4 空格，有些 IDE 默认 3 空格也可以，这本质上是个人偏好。
- **两种大括号风格**：开括号与语句同行可节省纵向空间、减少滚动；本教程系列为了让代码更易读、也更容易发现括号不匹配，把开括号单独放一行。
- **缩进**：函数大括号内的每条语句都要相对开括号缩进一个 Tab。
- **行长**：约 80 字符是事实上的上限；超长行应在合适处拆分——续行要么多加一层缩进，要么与上一行文字对齐。
- **拆分处的运算符**：若在 `<<`、`+` 等运算符处断行，运算符应放在下一行的开头，这样续行更清晰、运算符也能左对齐。
- **对齐与间距**：赋值、注释、代码块应适当对齐或留空，让代码更易读。
- **与现有代码保持一致**：在别人的代码库中应遵循其既有风格，而非个人偏好。
- **自动格式化**：多数 IDE 能格式化选区或整个文件（Visual Studio 用 *Edit > Advanced > Format Document* 与 *Format Selection*，Code::Blocks 用 *右键 > Format use AStyle*），建议为其设置快捷键；外部工具如 clang-format 也可用。
- **风格指南**：风格指南是一份精炼、带有主观倾向的约定文档，用于保证团队编程风格一致。常见的有 C++ Core Guidelines（Stroustrup/Sutter）、Google、LLVM、GCC/GNU；本教程系列一般偏向 C++ Core Guidelines。

## 最佳实践

- 尽量把每行控制在 80 字符以内。
- 小技巧：许多编辑器能显示某个列位置（如第 80 列）的竖直“列指示线”，让超长行一眼可见。
- 在已有项目中工作时，与项目已经采用的风格保持一致。
- 强烈建议使用自动格式化功能，以保持代码风格统一。
- 作者说明：本教程系列在其示例中采用自己那套久经验证的风格；但在编辑别人的代码库时，该项目的惯例优先于个人喜好。
