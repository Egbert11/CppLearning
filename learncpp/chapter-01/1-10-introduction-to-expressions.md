# 1.10 Introduction to expressions

> 原文：https://www.learncpp.com/cpp-tutorial/introduction-to-expressions/

## 核心概念

- **表达式（expression）**：由字面量、变量、运算符和函数调用组成的序列，用于计算出一个值；表达式不能为空。
- **求值（evaluation）**：执行表达式以取得其值的过程。
- **结果（result / 返回值）**：表达式求值后产生的值。
- **表达式的结果可以是什么（进阶）**：通常是一个值；有时是一个对象或函数；也可能什么都没有——当调用的函数不返回值、只是为副作用而调用时。
- **对初学者的简化**：本节暂时假定每个表达式都会求出一个值。
- **各项如何求值**：表达式中的每一项都会被求值，直到只剩一个值——字面量给出它自身的值，变量给出其存储的值，运算符把操作数合并为新值，函数调用给出函数的返回值。
- **带副作用的表达式**：较复杂。赋值（`x = 5`）的副作用是存入 5，而它自身求值为 `x`；流式输出（`std::cout << x`）会打印，并求值为 `std::cout`。
- **关键理解**：凡是语言期望一个值的地方，都可以放一个能求出值的表达式，随后该表达式会被求值成单个值。
- **表达式不是语句**：表达式不带分号，不能单独编译；它总是在某条语句中被求值。
- **包含表达式的语句形态**：形如“类型 标识符 { 表达式 };”，例如 `int x{ 2 + 3 };`，其中表达式 `2 + 3` 本身不带分号。
- **表达式语句（expression statement）**：“由表达式后跟一个分号组成的语句”。它可以编译，其求值发生在该语句执行时。
- **结果被丢弃**：在表达式语句中，表达式产生的值会被丢弃，因为没有东西使用它。
- **无用的表达式语句**：有些表达式语句语法合法却毫无效果，gcc 和 Clang 在检测到时会发出警告。
- **子表达式（subexpression）**：被用作操作数的表达式。
- **完整表达式（full expression）**：不是子表达式的表达式。
- **复合表达式（compound expression，口语用法）**：含有两次或更多次运算符使用的表达式。
- **测验（原文结尾）**：`int x;` 是语句但不含表达式（`x` 被定义、未被求值）；`int x = 5;` 是含表达式的语句；`x = 5;`、`foo();`、`std::cout << x;` 都是表达式语句。语句用于让程序执行某个动作，表达式则用于计算一个值。

## 最佳实践

本节没有标注为 Best practice / Warning 的规则框。要点提示如下：

- 关键理解（Key insight）：在 C++ 中期望单个值的地方，都可以改用能求出值的表达式，它会被求值为单个值。
- 进阶读者提示：带副作用的运算符会让表达式变得复杂，见 `x = 5`、`x = 2 + 3`、`std::cout << x` 三个示例。
- 相关内容：副作用的讲解见 1.9 节。
