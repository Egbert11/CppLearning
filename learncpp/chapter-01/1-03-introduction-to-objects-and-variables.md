# 1.3 Introduction to objects and variables

> 原文：https://www.learncpp.com/cpp-tutorial/introduction-to-objects-and-variables/

## 核心概念

- **数据（data）**：计算机可以移动、处理或存储的任何信息。程序就是一串指令，通过操作数据得到结果。
- **代码与数据**：程序本身严格说也是数据，但习惯上把程序叫"代码"，把它处理的信息叫"数据"。数据可来自文件、数据库、网络、用户键盘输入，或直接写在源码里的值。
- **值（value）**：一条数据，有时也叫数据值。例如数字（`5`、`-6.7`）、单引号里的字符（`'H'`、`'$'`）、双引号里的文本（`"Hello"`）。
- **引号规则**：单引号表示字符，双引号表示文本，数字不加引号；引号缺失或用错通常导致编译错误。
- **字面量（literal）**：直接写在源码里的值。它是只读的，所以要往内存里存数据还需要别的机制。
- **RAM**：随机存取存储器，计算机的主存。操作系统在运行时把程序加载进去，并额外预留内存给用户输入、文件/网络数据和计算结果。可把 RAM 想象成一排编号的盒子。
- **对象（object）**：C++ 不鼓励直接访问内存，而是通过对象——"一块能存放值的存储区域（通常在 RAM 或 CPU 寄存器中）"。对象还有其它属性（后续章节讲）。
- **变量（variable）**：有名字的对象。有了名字，之后就能再次引用它。
- **术语说明**：一般编程语境里 "object" 可能指无名的对象、变量或函数；在 C++ 里该词不含函数，本系列沿用这个较窄的含义。
- **定义（definition）**：一种特殊的声明语句，告诉编译器"我想要一个变量"。编译器在**编译期**记下名字和数据类型，并负责决定内存大小、存储方式、位置、生命周期等；此后每次出现该标识符，编译器都会把它映射到这个变量。
- **定义的位置**：变量在定义语句所在处被定义；目前应把变量定义在函数（如 `main()`）内部。
- **运行期与分配**：程序运行时，每个对象才获得实际的存储位置。预留这块存储叫**分配（allocation）**，一旦存储存在，对象就算被"创建"了。
- **数据类型（type）**：决定对象能存什么样的值。类型必须在**编译期**已知（这样编译器才知道需要多少内存），而且不改代码（重新编译）就无法改变。
- **整数（integer）**：没有小数部分、可直接写出的数，如 `4`、`27`、`0`、`-2`、`-12`。`int` 类型的变量即整数变量。C++ 还内置很多类型（如 `double`），也支持自定义类型。
- **一条语句定义多个变量**：**同一类型**的变量可以写在一个语句里、用逗号分隔。三个常见新手错误：重复写类型（`int a, int b;`）、在一条语句里混用类型（`int a, double b;`）、以及第三个与初始化有关的问题（下一节讲）。

## 最佳实践

- **Best practice**：尽管语言允许，**避免在一条语句里定义多个同类型变量**；应把每个变量单独定义在自己的一行上（并用单行注释说明它的用途）。
- 关键要点（Key insight）：
  - 程序是指令的集合，通过操作数据得到期望结果；
  - 单引号是字符值、双引号是文本值、数字不加引号；
  - 对象用于在内存中存值，变量是有名字的对象；
  - 定义语句用来告诉编译器"我们要用一个变量"；
  - 当实际存储被预留后，对象就被"创建"；
  - 对象的数据类型必须在编译期已知。
