# 1.x Chapter 1 summary and quiz

> 原文：https://www.learncpp.com/cpp-tutorial/chapter-1-summary-and-quiz/

> 说明：本小节官网编号为 **1.x**。

## 核心概念

- **语句（statement）**：让程序执行某个动作的指令，通常以分号结尾。
- **函数（function）**：按顺序执行的一组语句。每个 C++ 程序都需要一个名为 `main` 的函数，程序从 `main` 的第一条语句开始执行。
- **标识符（identifier）**：赋予函数、对象、类型、模板等的名字。
- **语法 / 语法错误**：语法是语言元素如何构成的规则集合；违反这些规则就是语法错误。
- **注释（comment）**：源码中供程序员阅读的说明。单行注释以 `//` 开始直到行尾；块注释以 `/*` 开始、以配对的 `*/` 结束。块注释不可嵌套。注释也可用来临时禁用代码（“注释掉”）。
- **数据与值**：数据是计算机可移动、处理或存储的信息；其中一条称为一个值，例如一个字母、一个数字或一段文本。
- **变量与定义语句**：变量是保存值的具名内存；由定义语句创建。运行时每个变量会被**实例化**，即获得一个内存地址。
- **数据类型与整数**：类型告诉编译器如何有意义地解释数据；整数是不带小数部分的数（如 4、27、0、-2、-12）。
- **拷贝赋值（copy assignment）**：用 `operator=` 给一个已创建的变量赋新值。
- **初始化 / 初始化器**：初始化是为对象提供起始值，初始化器是用于此目的的语法。C++ 有六种基本形式：

| 初始化类型 | 示例 | 备注 |
|---|---|---|
| 默认初始化 | `int x;` | 通常留下不确定的值 |
| 拷贝初始化 | `int x = 5;` | — |
| 直接初始化 | `int x ( 5 );` | 又称括号初始化 |
| 直接列表初始化 | `int x { 5 };` | 不允许窄化转换 |
| 拷贝列表初始化 | `int x = { 5 };` | 不允许窄化转换 |
| 值初始化 | `int x {};` | 通常置零 |

- **命名与偏好**：直接初始化有时称括号初始化；列表初始化（含值初始化）有时称统一初始化/大括号初始化。应优先使用大括号初始化，并优先使用初始化而非赋值。虽然一条语句可定义多个变量，但更推荐每行定义并初始化一个变量。
- **输出**：`std::cout` 配合 `operator<<` 把表达式的结果写到控制台。
- **换行**：`std::endl` 输出换行并立即刷新缓冲；`'\n'` 也输出换行但由系统决定何时刷新。不要误写成 `'/n'`（那是多字符字面量）。
- **输入**：`std::cin` 配合 `operator>>` 从键盘读取一个值。
- **未初始化变量 / 未定义行为**：从未赋值的变量是未初始化的；读取它会得到未定义行为，后果不可预测。
- **关键字**：具有特殊语言含义的保留名字，不能用作变量名。
- **字面量常量**：直接写在源码中的固定值，如 `5` 或 `"Hello world!"`。
- **操作、操作数、运算符、输出**：操作接收零个或多个输入值（操作数），用运算符表示，产生一个输出值。一元取一个操作数，二元取两个（左、右），三元取三个，零元取零个。
- **表达式、求值、结果**：表达式是由字面量、变量、运算符和函数调用组成的、求值为单个输出值的序列；计算它的过程叫求值，产生的值叫结果。
- **表达式语句**：表达式后加分号就构成一条语句。
- **开发流程**：先写几行或一个函数，编译、修错、确认可用，而不是等整个程序写完才编译。优先让代码能运行，之后再清理、补注释、处理错误、格式化、应用最佳实践、删除冗余逻辑。初稿通常是凌乱的，多数代码都需要反复打磨。

## 本章知识速览

以下为 Chapter 1（C++ Basics）全章要点清单（按 1.1–1.11 顺序）：

- **1.1 语句与函数**：程序是语句序列；语句以分号结尾（多数情况下）；函数是顺序执行的语句组；每个程序必须有 `main`；`int main()` 中 `int` 是返回值类型。
- **1.2 注释**：`//` 单行注释、`/* */` 块注释；块注释不能嵌套；注释用于解释“为什么”，可临时注释掉代码。
- **1.3 对象与变量**：对象是内存中可存储值的一块区域；变量是具名的对象；定义语句形如 `类型 标识符;`；变量在运行时被实例化（获得地址）。
- **1.4 变量赋值与初始化**：`=` 是拷贝赋值，给已存在的变量赋新值；初始化在创建时给出起始值，C++11 起优先使用大括号初始化 `int x { 5 };`；未初始化的变量含不确定值，读取会导致未定义行为。
- **1.5 iostream 简介**：`#include <iostream>`；`std::cout << x` 输出，`std::cin >> x` 输入；`'\n'` 换行，`std::endl` 换行并刷新；本系列偏好 `'\n'`。
- **1.6 未初始化变量与未定义行为**：未初始化的变量值不确定；读取它属于未定义行为，可能崩溃、得到错误结果或看似正常。
- **1.7 关键字与命名标识符**：关键字是保留字，不能作标识符；标识符命名规则（仅字母/数字/下划线、不以数字开头、区分大小写）；命名惯例（变量小写开头、camelCase 或 snake_case、描述性强、长度与作用域相称）。
- **1.8 空白与基本格式**：空白用于分隔元素与排版；空白数量无关紧要（引号内除外）；行长约 80 字符；一致缩进与对齐；遵循项目风格；善用自动格式化。
- **1.9 字面量与运算符**：字面量是源码中的固定值；操作/操作数/运算符/返回值；一元、二元、三元、零元；优先级（PEMDAS）；副作用的概念。
- **1.10 表达式简介**：表达式由字面量、变量、运算符、函数调用组成，求值为一个值；表达式不是语句；表达式语句的求值结果通常被丢弃；子表达式与完整表达式。
- **1.11 开发第一个程序**：增量开发（一次一小块、编译、测试）；`std::cin >> num` 读取输入；把表达式直接放进输出语句是首选做法；先让程序能运行，再改进与清理。

## 测验

- **第 1 题（概念）**：初始化与赋值有什么区别？
  - 参考答案：初始化在创建对象时给出初始值；赋值是之后改变已存在对象的值。因为创建只发生一次，初始化只发生一次，而赋值可以发生任意多次。
- **第 2 题（概念）**：什么是未定义行为？
  - 参考答案：当程序员做了 C++ 语言未明确规定的事情时就会发生未定义行为。后果范围很广——可能崩溃、得到错误结果，甚至表面上正常工作。
- **第 3 题（编码）**：编写一个程序，要求用户输入两个整数，然后打印它们的和与差。提示：要输出“一个句点加换行”，请使用 `".\n"` 而不是 `'.\n'`。
  - 参考运行（假设输入 6 和 4）：

    ```
    Enter an integer: 6
    Enter another integer: 4
    6 + 4 is 10.
    6 - 4 is 2.
    ```
