# 1.9 Introduction to literals and operators

> 原文：https://www.learncpp.com/cpp-tutorial/introduction-to-literals-and-operators/

## 核心概念

- **字面量（literal / literal constant）**：直接写在源码里的固定值，例如 `"Hello world!"` 或 `5`。
- **字面量与变量的区别**：两者都有值和类型，但字面量的值固定不变，变量的值可以通过初始化和赋值改变——这正是字面量属于“常量”的原因。
- **编译器如何处理**：字面量的值会被编译进可执行文件中，可直接使用；变量的值被拷贝到内存某处，使用时需从那里取回。
- **为什么字面量不能改**：它的值位于可执行文件里，而可执行文件生成后无法修改；保存变量值的内存则可在运行时改变。
- **操作 / 操作数 / 输出值 / 运算符**：一个操作接收零个或多个输入值（操作数），产生一个新值；表示该操作的符号叫运算符。例如在 `2 + 3` 中，`2` 和 `3` 是操作数，`+` 是运算符。
- **返回值（return value）**：操作产生的输出值在 C++ 中通常称为返回值。
- **常见运算符**：加 `+`、减 `-`、乘 `*`、除 `/`；赋值 `=`、插入 `<<`、提取 `>>`、相等 `==` 也都是运算符。有些运算符是关键字而非符号，如 `new`、`delete`、`throw`。
- **符号运算符的命名惯例**：把符号附在单词 operator 之后，如 `operator+`、`operator>>`。
- **元数（arity）**：一个运算符接收的操作数个数。C++ 中有四种：
  - **一元（unary）**：一个操作数，如 `-5` 中 `operator-` 翻转符号；
  - **二元（binary）**：两个操作数（左、右），如 `3 + 4` 中的 `operator+` 得 `7`；`<<`、`>>` 也是二元，左操作数是 `std::cout`/`std::cin`；
  - **三元（ternary）**：三个操作数——C++ 中只有条件运算符，后续章节介绍；
  - **零元（nullary）**：零个操作数——C++ 中只有 throw 运算符，后续章节介绍。
- **运算符的多种含义（重载）**：同一符号在不同语境下含义不同；`operator-` 一元时表示取负，二元时表示相减。
- **运算符的链接**：一个运算符的输出可作为另一个的输入。在 `2 * 3 + 4` 中先算乘法得 `6`，它成为加法的左操作数，最终得 `10`。
- **优先级**：算术运算遵循标准数学顺序——括号、指数、乘除、加减，缩写为 PEMDAS。
- **返回值与副作用**：多数运算符只计算返回值（如 `-5` 得 `-5`，`2 + 3` 得 `5`）；少数运算符没有返回值（`delete` 和 `throw`）。
- **副作用的定义（C++）**：运算符或函数除产生返回值之外的、可观察到的效果。例如 `x = 5` 改变了 `x`，`std::cout << 5` 向控制台打印。
- **术语提醒**：日常语境里“副作用”暗示次要、不受欢迎的结果；C++ 里它只表示“除返回值之外可观察到的效果”，有些运算符主要就是为其副作用而使用的。
- **进阶：带副作用的运算符返回其左操作数**：`x = 5` 返回 `x`，`std::cout << 5` 返回 `std::cout`，这正是可以链式书写的原因：`x = y = 5` 按 `x = (y = 5)` 求值；`std::cout << "Hello " << "world!"` 按 `(std::cout << "Hello ") << "world!"` 求值。

## 最佳实践

本节没有标注为 Best practice / Warning 的规则框。要点提示如下：

- 关键理解（Key insight）：字面量是直接插入源码的值，通常也直接出现在可执行代码中（除非被优化掉）；对象和变量表示保存值的内存位置，值可按需取回。
- 作者说明：符号运算符的惯例写法是把符号附在 operator 之后，如 `operator+`、`operator>>`。
- 关于优先级助记：有些地区把 PEMDAS 教成 PEDMAS、BEDMAS、BODMAS 或 BIDMAS，含义相同。
