# 15.6 Static member variables

> 原文：https://www.learncpp.com/cpp-tutorial/static-member-variables/

## 核心概念

- **静态存储期回顾**：全局变量与静态局部变量在程序启动时创建、结束前销毁，离开作用域后仍保留其值。
- **类里 `static` 的两种用法**：类新增静态成员变量和静态成员函数；本节讲前者。
- **普通成员变量是"每个对象一份"**：每个被实例化的对象拥有自己的一份副本，改变一个对象的成员不会影响另一个。
- **静态成员变量是共享的**：与普通成员变量不同，静态成员变量被类的所有对象共享——总共只有一份，通过任意对象都能访问。
- **静态成员不依附于对象**：即使一个对象都没实例化，静态成员也存在，因为它的生命周期是整个程序而非某个对象。
- **概念上就是"类作用域里的全局变量"**：它可以被看作住在类作用域区域里的全局变量，与命名空间作用域的变量几乎一样。
- **首选访问语法**：用"类名 + `::`"访问，这样无需实例化任何对象。
- **声明与定义分离**：在类内声明静态成员只是声明它的存在（类似前向声明）；还需要在全局作用域给出显式定义。
- **定义行做两件事**：实例化该变量，并可对其初始化；没有初始化器时成员被零初始化。
- **访问控制不约束定义**：即使成员声明为 private 或 protected，也可以在类外定义并初始化它，因为定义不是一次"访问"。
- **定义放在哪里**：非模板类——若类在头文件中，定义放进该类的 `.cpp`；若类在 `.cpp` 中，定义就写在类下方；也可标 `inline` 后放进头文件。绝不要把非 inline 定义放进头文件，多次包含会导致"重复定义"的链接错误。
- **模板类不同**：模板类的静态成员定义通常直接写在头文件里、模板类定义的下方；它是隐式 inline 的，不违反 ODR。
- **类内初始化捷径一**：静态 const 整型（含 `char`、`bool`）或 const 枚举是编译期常量，可在类内定义并初始化。
- **类内初始化捷径二（C++17）**：静态成员可以是 inline 变量，于是无论是否为常量都能在类内初始化——本节推荐这种写法。
- **类内初始化捷径三**：`constexpr` 成员自 C++17 起隐式 inline，所以静态 `constexpr` 成员无需写 `inline` 就能在类内初始化；适用于支持 constexpr 初始化的类型。
- **用途一——唯一 ID**：共享计数器让每个对象拿到不同 ID，按创建顺序递增；调试数据数组时尤其有用。
- **用途二——查找表**：把查找表做成静态，可让所有对象共用一份，而不是每个对象各存一份，从而省内存。
- **类型推导规则**：只有静态成员可以使用 `auto` 或 CTAD；非静态成员不行，因为非静态成员会出现某些歧义或反直觉的情况，而静态成员不会。

## 最佳实践

- **Best practice**：用类名和作用域解析运算符（`::`）访问静态成员。
- **Best practice**：把静态成员做成 `inline` 或 `constexpr`，以便能在类定义内初始化。
- **Key insight**：静态成员是"住在类作用域区域里的全局变量"。
