## 核心概念

- **运算符优先级**：当优先级不清楚或可能引起混淆时就用括号，清晰胜过简短。
- **算术运算符**：与普通数学一致；取余运算符 `%` 返回整数除法的余数。
- **自增/自减运算符**：让加减一变得容易；尽可能优先用前缀形式，尽量避免后缀形式。
- **副作用**：函数实参的求值顺序未规定，因此不要在同一条语句中让带副作用的变量出现多次。
- **逗号运算符**：能把多条语句塞进一行，但通常分开写更好。
- **条件运算符（`?:`）**：也叫“算术 if”，是三元运算（三个操作数）。`c ? x : y` 中，`c` 为真时求值 `x`，否则求值 `y`。
- **`?:` 的括号规则**：当它出现在复合表达式中时，把整个条件运算符括起来；当条件含任何运算符（函数调用运算符除外）时把条件括起来——这么做是为了可读性。
- **关系运算符与浮点**：允许用关系运算符比较浮点值，但对它们做相等/不等比较有风险。
- **逻辑运算符**：它们使复合条件语句成为可能。

## 最佳实践

- 怀疑就用括号；优先前缀自增/自减；避免在一条语句里对同一变量重复施加副作用；把逗号运算符的语句拆开以提升可读性。
- 原文无显式标注的 Best practice / Warning 框；仅有测验提示（hint）：当返回类型是 `std::string_view` 时，从函数返回 C 风格字符串字面量是可以的。

## 本章知识速览

- **优先级与结合性**：决定运算符如何与操作数分组、按何顺序做值计算，但**不**决定操作数的求值顺序。非平凡表达式请加括号。
- **算术运算符**：`+ - * / %`，以及一元 `+`、`-`。整数除法截断小数；任一操作数为浮点则为浮点除法。整数除以 0 是未定义行为。
- **算术赋值运算符**：`+= -= *= /= %=`。
- **取余 `%`**：仅用于整数，结果符号与被除数相同；宜与 0 比较。
- **幂**：C++ 无幂运算符，`^` 是按位异或。`std::pow()` 返回 double；整数幂宜自写函数并注意溢出。
- **自增/自减**：前缀先变后用、后缀先用后变；不关心返回值时二者等价。优先前缀。
- **副作用与求值顺序**：不要在同一条语句中对同一变量施加多次副作用。
- **逗号运算符**：优先级最低，返回右操作数的值；一般避免，`for` 循环除外。
- **条件运算符 `?:`**：唯一的三元运算符；可用于初始化等表达式语境。注意优先级，处于复合表达式中要整体加括号；混合类型时注意转换规则。
- **关系运算符**：`> < >= <= == !=`，返回布尔值。
- **浮点比较**：避免用 `==`、`!=` 比较浮点值；`< >` 在两数相近时也不可靠。可用绝对+相对 epsilon 的近似相等函数。
- **逻辑运算符**：`! && ||`。`!` 优先级高，作用于复合表达式时需加括号；`&&` 高于 `||`，混用要加括号。二者短路求值，且左操作数先求值。避免与副作用表达式搭配。德摩根定律：`!(x && y) == !x || !y`。C++ 无逻辑 XOR，可用 `!=` 变通。

## 测验

- **Q1**：完成下面程序中的两个函数（模板见原文，main 已给出，见 [6-09-quiz1.cpp](6-09-quiz1.cpp)）。
  - `getQuantityPhrase(int)` 按数量返回描述词：`< 0` → "negative"，`0` → "no"，`1` → "a single"，`2` → "a couple of"，`3` → "a few"，`> 3` → "many"。
  - `getApplesPluralized(int)` 在数量为 1 时返回 "apple"，否则返回 "apples"；**该函数必须使用条件运算符**。
  - 提示（原文）：返回类型为 `std::string_view` 时，从函数返回 C 风格字符串字面量没问题。
  - 参考示例输出：
    ```
    Mary has a few apples.
    How many apples do you have? 1
    You have a single apple.
    ```
  - 参考解答：`getQuantityPhrase()` 用连续的 `if` 返回；`getApplesPluralized()` 用 `(num == 1) ? "apple" : "apples"`；两者均返回 `std::string_view`。见 [6-09-quiz1.cpp](6-09-quiz1.cpp)。
