# 6.2 Arithmetic operators

> 原文：https://www.learncpp.com/cpp-tutorial/arithmetic-operators/

## 核心概念

- **一元算术运算符（unary arithmetic operators）** 有两个：一元加 `+` 与一元减 `-`。一元运算符是只接受一个操作数的运算符。
- **一元减**：结果为操作数乘以 -1。若 `x = 5`，则 `-x` 为 `-5`。
- **一元加**：返回操作数本身（`+5` 为 `5`，`+x` 为 `x`）。它通常是多余的，存在主要是为了与一元减对称。
- **书写规范**：两个一元运算符都应紧贴操作数写（写 `-x` 而非 `- x`），便于阅读。
- **避免混淆**：一元减与二元减法符号相同。在 `x = 5 - -3;` 中，第一个减号是二元减法，第二个是一元减。
- **二元算术运算符** 有五个：加 `+`、减 `-`、乘 `*`、除 `/`、取余 `%`。二元运算符接受左右两个操作数。
- **简易运算符**：加、减、乘与日常数学一致，没有特别之处。
- **两种除法模式**：除法依操作数类型表现不同。若任一操作数是浮点，则做浮点除法并保留小数（如 `7.0 / 4 = 1.75`）；注意浮点运算可能有舍入误差。
- **整数除法**：当两个操作数都是整数时，小数部分被丢弃，返回整数。如 `7 / 4 = 1`，`-7 / 4 = -1`。
- **强制浮点除法**：用 `static_cast<>` 把整数转为浮点类型即可保留小数（回顾 4.12 把 char 转为整数）。
- **除以零**：整数除法中除数为 0 会导致未定义行为；样例程序若输入 0 很可能会崩溃。
- **除以 0.0**：浮点零除的结果是实现定义的（由编译器/架构决定）。在 IEEE754 架构上结果是 `NaN` 或 `Inf`；其它情况很可能是未定义行为（NaN/Inf 见 4.8）。
- **算术赋值运算符（arithmetic assignment operators）** 有五个：`+=`、`-=`、`*=`、`/=`、`%=`。与其写啰嗦的 `x = x + 4`，不如写 `x += 4`。
- **修改型 vs 非修改型运算符**：**修改型运算符（modifying operator）** 能改变其操作数。多数 C++ 运算符只计算并返回值，但有两类内建运算符会修改左操作数：赋值运算符（`=`、算术赋值运算符，以及位运算的 `<<=`、`>>=`、`&=`、`|=`、`^=`）和自增/自减运算符 `++`、`--`（见 6.4）。注意 `==`、`!=`、`<=`、`>=` 是非修改的比较运算符，不属于此类（见 6.7）。
