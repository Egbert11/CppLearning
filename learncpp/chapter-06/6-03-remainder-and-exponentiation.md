# 6.3 Remainder and Exponentiation

> 原文：https://www.learncpp.com/cpp-tutorial/remainder-and-exponentiation/

## 核心概念

- **取余运算符（`operator%`）**：也叫 modulo / modulus，返回整数除法后的余数。例：7 / 4 = 1 余 3，故 `7 % 4 = 3`。它**只能作用于整数操作数**。
- **整除性判断**：若 `x % y` 为 0，则 x 能被 y 整除。这是该运算符最常见的用途。
- **第二个操作数更大时**：除数除不尽被除数（进 0 次），被除数本身就是余数（如 `2 % 4 = 2`）。
- **负数**：`operator%` 接受负操作数，`x % y` 的结果符号**始终与 x 相同**。故 `-6 % 4 = -2`，而 `6 % -4 = 2`。
- **术语**：标准未给 `operator%` 官方名称；C++20 描述其为“第一个表达式除以第二个表达式所得的余数”。称其为“modulo（模）”可能误导，因为当恰有一个操作数为负时，数学上的模定义可能不同（-21 mod 4 = 3，而 -21 余 4 = -1）。故本节更偏向“remainder（余数）”这一更准确的叫法。
- **负被除数的陷阱**：余数可以为负，因此 `(x % 2) == 1` 这种朴素的奇数判断对负奇数会失效（如 `-5 % 2 = -1`）。与 0 比较可避免符号问题。
- **没有指数运算符**：`^` 在 C++ 中是按位异或（Bitwise XOR），不是幂。C++ 没有幂运算符。
- **`std::pow()`**：包含 `<cmath>` 后调用 `pow()`。其参数与返回值都是 `double`，因此 `pow()` 的结果可能不精确（浮点舍入）。
- **整数幂**：最好自己写函数。本节版本用“平方求幂（exponentiation by squaring）”算法以提高效率；还有一个带溢出检查的变体。
- **溢出风险**：整数幂通常会溢出整型类型，这大概正是标准库不提供此类函数的原因。
- **测验答案**：`6 + 5 * 4 % 3` 解析为 `6 + ((5 * 4) % 3)` = `6 + (20 % 3)` = `6 + 2` = `8`；因为 `*` 与 `%` 同级且左结合。

## 最佳实践

- 尽可能把取余运算符（`operator%`）的结果**与 0 比较**。
- Warning：绝大多数情况下，整数幂会溢出整型类型。这很可能就是标准库当初不提供此类函数的原因。
- 相关提示（For advanced readers）：`constexpr` 说明符使函数在用于常量表达式时可在编译期求值；否则表现为普通运行期函数（详见 9.6 的 assert、F.1 的 constexpr 函数）。
